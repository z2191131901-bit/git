# 惯导与多传感器融合验证记录

验证环境：Windows、MinGW-w64 GCC 8.1.0。
本批新增3个独立程序，仓库累计37个 C 示例。

## 编译运行

在仓库根目录执行：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1
~~~

每个源文件独立编译，参数为 -std=c99 -Wall -Wextra -Werror -pedantic，并链接 -lm。
断言保持启用，没有设置 NDEBUG。可执行文件写入系统临时目录，不提交仓库。
ExecutionPolicy Bypass 只作用于这一 PowerShell 进程，不改变系统永久策略。

## 检查内容

| 示例 | 断言覆盖 |
| --- | --- |
| 编码器＋陀螺仪 | 直行、倒车、原地转动、解析四分之一圆终点、零偏误差、非法输入不改状态 |
| 三维惯性递推 | 水平与倾斜静止、恒加速度解析解、绕Z轴旋转、加速度零偏漂移、确认静止后速度清零、非法dt |
| 平面EKF | 手算标量更新、角度跨界、无效参数、门控拒绝不改状态、协方差逐步Cholesky检查、偏差估计、位置中断与恢复、融合与无外部辅助对比 |

EKF 真值用解析圆周公式生成，不与被测的一阶离散位置递推共用真值生成式。
轮速、磁航向、位置分别以 50/10/5 Hz 更新，IMU预测100 Hz。
位置从第10秒至第18秒中断，期间轮速和航向保持可用。

三次拒绝是一次磁航向标量和两次位置标量，不是三个位置数据包。
x/y 使用互不相关噪声假设下的顺序标量更新，门控也是逐轴进行。

## 结果能说明什么

结果说明这些确定性模型检查通过，公式、边界处理和主要数据流得到验证。
不能把 0.015727 m 仿真误差当成真实硬件定位精度。
未验证真实打滑、温漂、磁环境、延迟、安装杆臂、真实GNSS/UWB数据和统计一致性。
纯惯导示例未实现地球模型与完整三维误差状态滤波；静止速度清零不是完整卡尔曼ZUPT。
