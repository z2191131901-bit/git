# PID：先让目标和实际值靠近，再认识三个字母

[打开演示代码](PID.c) · [打开算法函数](../公共代码/PID核心.h) · [返回学习入口](../新手从这里开始.md)

你只需要先会变量、加减乘除和循环。导数、积分等数学名词会先用数字解释。
第一遍读到第6节，能手算一拍PI，就已经完成本篇最重要的入门目标。

## 1. 我们到底要控制什么

想象一个小风扇。你希望它转得快一点，但只设一个固定PWM，负载改变后转速也会改变。

PWM是让电路快速开关，用一段时间里“开着的比例”影响平均驱动。
占空比就是这个比例。这里先把驱动命令看成可以调大或调小的数。

有速度传感器后，每次可以做三件事：

~~~text
读取实际速度 → 与目标比较 → 修改驱动命令 → 再次读取实际速度
~~~

这种“看结果后再调整”的循环叫闭环。
测量返回控制器，叫反馈。目标减实际值，叫误差。

~~~text
目标100，实际80：误差20，应该考虑增加驱动。
目标100，实际110：误差−10，应该考虑减小驱动。
~~~

本例要求“正向驱动增大，测量通常也增大”。驱动和测量方向必须先一致。

## 2. PID放在循环的哪里

~~~mermaid
flowchart LR
    A[目标] --> B[PID计算]
    C[实际测量] --> B
    B --> D[驱动命令]
    D --> E[被控制的对象]
    E --> C
~~~

PID的输入是目标、实际测量、两次计算的时间间隔。
输出是一个驱动命令。

输出不自动代表PWM。它可以是电压、电流或其他单位，要由使用者约定。
本篇电脑仿真使用无具体物理单位的归一化数值，范围−1到1。
“归一化”就是把量按某个尺度表达，方便展示通用行为。

控制器只计算命令；被控制的对象收到命令后，才产生下一次测量。

## 3. 先只看P：差多少，就按比例调整多少

P是比例。规则很简单：

~~~text
P输出 = Kp × 误差
~~~

Kp是自己设置的比例系数。
例如Kp=0.1，误差20，P输出2；误差变为5，P输出0.5。

Kp较大，通常对误差反应更强，也可能振荡。
P本身没有“记忆”；同样误差会得到同样P输出。

为什么有时实际值总差一点？
如果维持某个转速需要持续驱动，P可能靠保留一点误差来提供这个驱动。
于是只用P可能在目标附近停住，却始终没有完全达到目标。

## 4. 再加I：把持续存在的误差记下来

I是积分。先把它理解成“每隔一段时间，往记忆里存一点误差贡献”：

~~~text
新的I贡献 = 旧的I贡献 + Ki × 误差 × dt
~~~

dt是两次计算之间隔的秒数。例如0.01s就是10ms。
Ki决定记忆增长速度。这里保存的integral已经乘过Ki，单位与输出相同。

假设Ki=1、每0.1s算一次、误差连续保持1：

| 更新次数 | 更新前I | 本次增加 | 更新后I |
| --- | --- | --- | --- |
| 1 | 0 | 1×1×0.1=0.1 | 0.1 |
| 2 | 0.1 | 0.1 | 0.2 |
| 3 | 0.2 | 0.1 | 0.3 |

同样的误差持续越久，I提供的命令越大。
误差反向时，I也能逐渐减小。
即使误差后来变成0，已有I仍可保持，用来提供维持目标所需的持续驱动。

上表为了理解计算，假设误差不变。真实闭环中对象会响应，下一拍误差一般会变。

## 5. 最后认识D：看实际值变化有多快

D是微分。这里先用两个测量值算“每秒变化多少”：

~~~text
测量变化率 = (本次测量 − 上次测量) / dt
D输出 = −Kd × 测量变化率
~~~

例如测量从0增加到0.1，经过0.01s，变化率是10。
Kd=1时，D输出−10，给上升趋势施加阻尼，即减弱继续加速上升的命令。
D不是直接预测未来，而是利用最近的变化趋势。

本实现对测量变化求D。目标突然改变、测量没变时，D不会仅因目标变化跳起来。
测量噪声也会造成很大的变化率，所以代码有平滑处理。
第一次学习可以先用Kd=0，只学PI；很多控制任务也主要使用PI。

## 6. 对照代码，手算第一个输出

演示文件最开始设置：

~~~c
PidConfig cfg = {2, 1, 0, 0, -100, 100};
PidState state = {0};
double u = 0;
int ok = pid_update(&state, &cfg, 1, 0, 0, 0.1, &u);
~~~

参数按函数声明的顺序读：

| 这次传入的值 | 代表什么 |
| --- | --- |
| &state | 控制器记忆的地址 |
| &cfg | 参数配置的地址 |
| 1 | 目标 |
| 0 | 实际测量 |
| 0 | 前馈；本次不用，填0 |
| 0.1 | dt=0.1秒 |
| &u | 输出写到u变量 |

前馈是根据已知需求预先给出的命令，本篇入门时先忽略。
&表示交出变量地址；函数通过这个地址更新state或u。

配置中Kp=2、Ki=1、Kd=0，微分滤波时间常数0，输出范围−100到100。
初始I为0。手算：

~~~text
误差 = 1−0 = 1
P = 2×1 = 2
新I = 0 + 1×1×0.1 = 0.1
D = 0
输出 = P + I + D = 2.1
~~~

这就是程序打印的hand calculation output=2.100000。
如果误差下一拍仍为1，新I变成0.2，输出2.2。

## 7. 为什么“输出限幅”之外还要管理I

限幅就是不让输出超过允许范围。
例如驱动最大只能接受1，PID算出2.1，最终也只能给1。

如果控制器仍一直增加I，输出虽然保持1，内部记忆却越来越大。
目标降低后，大量旧I可能让驱动迟迟降不下来。
这种现象叫积分饱和或积分累积过度。

本实现用“条件积分”：
先试算新I；如果它会让已经超过上限的命令更大，就取消本次增加。
如果积分方向有助于退出限制，则允许更新。

把第6节的上限改为1：

~~~text
试算输出2.1 > 上限1
本次I又想增加0.1，因此取消这一笔
I保持0，P仍为2
最终命令限制为1
~~~

这里状态里的I是0，不是0.1。
这个规则只处理函数知道的上下限，实际驱动还有其他限制时需要额外反馈。

## 8. 参数和记忆为什么分成两个结构体

| 名称 | 放什么 | 何时变化 |
| --- | --- | --- |
| PidConfig | kp、ki、kd、滤波参数、输出范围 | 配置或调参时 |
| PidState | I贡献、上次测量、平滑后的变化率、是否有历史 | 每次更新时 |

`PidState state={0}` 在启动时执行一次。
如果每次循环都清零，I无法积累，D也无法比较前后测量。
两个电机各需要一份state；不能共用同一份历史。

单位也要一致。目标为rpm，测量也必须为rpm。
dt必须用秒，10ms写成0.01，不能写成10。

## 9. 第一次读源码按这个顺序

先打开PID.c，找到最开始的手算调用；再打开PID核心.h里的pid_update。

| 代码部分 | 先理解的意思 |
| --- | --- |
| 输入检查 | 无效地址、非有限数值、非法dt等会被拒绝 |
| error | 本次目标减测量 |
| measured_rate | 与上次测量比较；首次没有历史，取0 |
| next.integral | 尝试把本次误差贡献存入记忆 |
| raw | 限幅前的命令总和 |
| 条件积分判断 | 是否取消让超限更严重的这笔I |
| command | 限制到允许范围后的输出 |
| *state、*output | 全部计算成功后，写回新记忆和输出 |

next是旧状态的一份临时副本。中途检查失败时，不污染原来的状态。
返回1只表示本次计算成功；不表示电机稳定或已经到达目标。

## 10. 不接电机，怎样在电脑上验证

从仓库根目录运行：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 PID.c
~~~

需要gcc能从命令行找到。主要输出：

~~~text
hand calculation output=2.100000
PID final y=0.50000000 reference=0.5
pid: PASS
~~~

y是电脑中模拟对象的当前测量，u是PID输出命令。
它们通过下面这行产生联系：

~~~c
y = decay*y + (1-decay)*u;
~~~

dt=0.01s时，decay约0.9802。
也就是下一拍约保留98.02%的旧y，再加1.98%的当前u，模拟一个响应有惯性的对象。
这个教学对象允许正负命令，不对应某台真实电机。

循环2000次相当于模拟20s，不要求电脑实际等待20s。
目标为0.5，最后y接近0.5。
main还检查输出饱和、D的方向、D平滑和非法dt。PASS表示这些检查通过。
不要定义NDEBUG关闭断言验证。

## 11. 新手可以做的三个小实验

**只用P。** 在闭环实验前把cfg设置为`{2,0,0,0,-1,1}`。
此教学对象目标0.5时，理论稳态y约0.3333，可观察持续误差。
原来的“最终到0.5”断言此时应按新实验目的调整。

**加回I。** 使用`{2,4,0,0,-1,1}`，观察持续误差怎样消失。
只修改闭环实验使用的配置，避免误改前面的独立验证条件。

**改变计算周期。** 将闭环的dt从0.01改为0.02，并让decay使用新dt。
相同2000次现在代表40s；比较相同时长时应调整循环次数。
实际采样周期与传入dt要一致。

不要直接在功率电机上尝试教学参数。先用这个模拟对象理解变化。

## 12. 下一步与进阶内容

读懂PI后，可读[串级PID](../25_串级PID/讲解.md)，理解两个控制循环怎样配合。
然后再读[FOC入门](../76_FOC电流与速度控制/讲解.md)。

微分平滑公式为：

~~~text
alpha = dt / (tau + dt)
平滑变化率 = 旧平滑变化率 + alpha × (本次变化率 − 旧平滑变化率)
~~~

tau是平滑时间常数，单位秒。tau=0代表不平滑，Kd=0才是关闭D。
第一次可以跳过参数单位的推导、连续对象方程和微分实现细节。
