# 位置式 PID：误差、累积误差和变化趋势

对应代码：[PID.c](PID.c)。完整控制器函数放在 [PID核心.h](../公共代码/PID核心.h)，串级和前馈篇也使用它。

## 1. 先把闭环画在脑子里

你给电机一个目标速度，编码器测出实际速度。控制器计算两者差距，输出电压、电流或归一化PWM，再读取下一次测量。

这里的“位置式”指直接算出控制输出的绝对值，不是说它只能控制位置。速度、温度、压力等也可以使用这种形式。

本例假设正作用对象：输出增大，测量通常也增大。如果电机正负方向相反，应先统一驱动和测量符号，否则负反馈会变成正反馈。

## 2. 三部分分别做什么

```text
error = reference - measurement
P = Kp * error
I_new = I_old + Ki * error * dt
D = -Kd * 测量变化率
raw_output = feedforward + P + I_new + D
```

P 看当前差距，I 记住过去的持续偏差，D 观察测量变化趋势并提供阻尼。

这里的 D 对测量求导，而不是对误差求导。因此设定值从0突然跳到1、测量还没动时，不会因为目标变化直接产生很大的 D 冲击。P 仍会正常响应目标变化。

## 3. 变量和单位

| 字段 | 含义 |
| --- | --- |
| kp | 输出单位/误差单位 |
| ki | 输出单位/(误差单位×秒) |
| kd | 输出单位×秒/误差单位 |
| derivative_tau | 微分滤波时间常数，秒 |
| integral | 已乘Ki的积分输出贡献，不是原始误差积分 |
| minimum/maximum | 实际执行器接受的输出范围 |
| dt | 控制间隔，秒 |

PidState state={0} 只在初始化时执行。每个被控通道使用自己的状态；如果每次采样清零，积分和微分历史都会丢失。

PidConfig 保存参数，PidState 保存随时间变化的历史。把两者分开，是为了让你看清“调的参数”和“运行中的记忆”不是同一类数据。

## 4. 从代码入口开始读

第一步检查指针、有限数值、dt>0和参数范围。函数返回0代表没有完成本次计算，原状态和输出不变；返回1不代表真实系统已经稳定。

第二步计算 error。reference 和 measurement 必须同单位，例如都为rad/s，不能一个是rpm另一个是rad/s。

第三步计算测量微分。首次没有历史，取0；之后为：

```text
measured_rate = (measurement-previous_measurement)/dt
alpha = dt/(derivative_tau+dt)
filtered_rate += alpha*(measured_rate-filtered_rate)
D = -Kd*filtered_rate
```

如果测量上升，D通常为负，阻止继续过快上升。微分会放大高频噪声，因此常配低通。tau=0表示不做平滑，不等于关闭D。

## 5. 为什么积分还要经过一次判断

执行器有极限。目标要求输出10，而实际只能输出1，继续积分并不能让执行器更强，却会留下很大的历史积分，目标降低后仍迟迟退不出来。

代码先试算积分和总输出：

- 超过上限，并且这次积分还要增加输出：取消本次积分。
- 低于下限，并且这次积分还要减少输出：取消本次积分。
- 积分方向有助于退出饱和：允许积分。

这叫条件积分。最后再把总输出限制到真实范围。前馈也参与总输出判断，否则前馈已经占用的执行器余量会被忽略。

这个方法处理本函数知道的饱和。如果后面的驱动又有更严格限流、死区或变化率限制，控制器还需要知道实际执行结果，不能仅靠这里的限幅判断。

## 6. 手算一次

Kp=2，Ki=1，Kd=0，目标1，测量0，dt=0.1，初始I=0，输出范围足够大：

```text
error=1
P=2*1=2
I_new=0+1*1*0.1=0.1
D=0
output=2.1
```

如果上限只有1，试算2.1超过上限且积分还在增加，于是I保持0，最后输出限制为1。

## 7. 怎么开始调参数

先统一采样时间、测量符号和执行器范围。可以先令Ki=Kd=0，从较小Kp开始，观察响应速度与振荡；然后逐步加Ki改善持续偏差。只有确有需要、测量质量允许时再加入Kd和微分滤波。

这不是通用自动整定法。不同惯性、时延和执行器约束需要不同参数。Ki=0时本实现会清掉积分贡献；在线切换参数若要无扰，需要另外设计状态跟踪。

## 8. 示例中的仿真对象

```text
y_dot = (-y+u)/0.5
dt=0.01秒
y_next = exp(-dt/0.5)*y + (1-exp(-dt/0.5))*u
```

这是归一化一阶对象，时间常数0.5秒，控制输出范围[-1,1]。它不是某一款电机的真实模型。

检查包括：手算2.1、长期不可达目标下积分不增长、目标阶跃不引发D冲击、测量变化的D方向、闭环跟踪及非法dt。计算与状态存储均O(1)。
