# Madgwick 六轴：沿梯度减小姿态方向误差

对应代码：[Madgwick姿态融合.c](Madgwick姿态融合.c)。

## 1. 先理解它要解决的问题

这里实现经典 IMU 版本，输入陀螺仪和加速度计。它与 Mahony 都能修正倾角，但生成校正方向的方式不同。不是九轴 MARG，也不是 Fusion 的修订算法。

## 2. 输入、输出与约定

四元数机体到世界，gyro 使用 rad/s，dt 使用秒；静止比力指向世界 +Z，accel 内部归一化。beta≥0 控制校正强度，accel_valid 决定是否使用方向参考。

## 3. 公式先看懂每个量

```text
f = 根据四元数预测的向上方向 - 实测单位方向
J = f 对四元数四个分量的偏导矩阵
gradient = J^T * f
q_dot = 0.5*q*[0,gyro] - beta*gradient/|gradient|
q_new = normalize(q + q_dot*dt)
```

## 4. 按执行顺序读代码

### 第 1 步：先算陀螺仪导数

将 gyro 写成纯四元数，与 q 相乘后乘 0.5。此时 derivative 的四项仍是变化率，不是新姿态。

### 第 2 步：构造三项方向残差

f1/f2/f3 分别表示预测向上方向 X/Y/Z 分量与实测分量的差。残差为零表示参考方向已经对齐。

### 第 3 步：展开梯度

gradient 的四行是 J^T*f。比如对 w 的偏导来自 f1 中的 -2wy 和 f2 中的 2wx，因此 w 梯度为 -2y*f1+2x*f2。不要把它理解成对四元数分量直接做平均。

### 第 4 步：归一化梯度

把梯度除以长度，只保留下降方向，再乘 beta。从导数中减去这一项，表示沿减小误差的方向移动。长度为零时跳过，防止 0/0。

### 第 5 步：积分与归一化

四个导数分别乘 dt，加到旧 q 上，再归一化。全部成功才写回。即使 gyro 为零，也仍要允许加速度参考修正姿态。

## 5. 代入数字算一次

设 q 对应横滚 10°，加速度实测 [0,0,1]。预测 Y 分量为 sin10°≈0.17365，预测 Z 分量为 cos10°≈0.98481，因此 f2≈0.17365，f3≈-0.01519。梯度据此指向增大残差的方向，代码减去它，逐步把错误横滚拉回。

## 6. 参数怎样选

beta 越大，方向校正更强，但更容易受运动加速度和噪声影响。归一化梯度使用近似固定步幅，最优点附近可能小幅振荡；beta*dt 越大，这种现象越明显。beta=0 退化为纯陀螺仪一阶积分。

## 7. 常见错误与适用边界

六轴无法确定绝对航向，也没有独立陀螺仪零偏状态。accel_valid 需要外部判断；不能在自由落体时归一化零向量。姿态初始化和大角度收敛仍需考虑，不能把模拟收敛当作所有实况保证。

## 8. 示例验证了什么

验证带横滚误差、零角速度下收敛；零残差不除零；无加速度参考时纯航向积分；非法有效参考不破坏姿态。复杂度与额外存储 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。
