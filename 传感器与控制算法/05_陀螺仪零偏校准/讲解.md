# 陀螺仪静止零偏：先修正“不转也有读数”

对应代码：[陀螺仪零偏校准.c](陀螺仪零偏校准.c)。

## 1. 零偏是什么
可以把角速度测量简化为：
```text
测量值 = 真实角速度 + 零偏 + 随机噪声
```
在通常的低成本 IMU 入门场景中，把设备固定静止，真实转动可近似看作零。多次读数的均值就能估计该状态、该温度下的零偏。高精度惯导还需考虑地球自转等因素，不在本例范围内。

例如 Z 轴始终多报 0.04 rad/s，直接积分 10 秒就可能多积累约 0.4 rad 的角度。零偏校准应在姿态积分之前进行。

## 2. 必须先满足的条件
本函数不会自动检测静止。调用者应保证采集期间设备固定、无明显振动，量程与单位不变，并在需要时先等待温度稳定。

运动中的平均角速度不等于零偏。把设备匀速旋转的数据拿来标定，会把真实运动错误地减掉。

## 3. 为什么求平均
静止时假设噪声近似零均值：
```text
bias_x ≈ (gx_1 + gx_2 + ... + gx_N)/N
```
Y、Z 轴同理。更多样本有助于减弱随机波动，但不能消除温漂、相关噪声和错误的静止假设。样本数量不是越大就一定越准确。

四个 X 轴样本为 0.01、0.02、0.03、0.02：
```text
总和 = 0.08 rad/s
零偏 = 0.08/4 = 0.02 rad/s
```
Z 轴的 0.03、0.04、0.05、0.04 得到 0.04 rad/s。新测量为 0.14 rad/s 时，修正结果为 0.10 rad/s。

## 4. 二维数组怎么读
参数 const float samples[][3] 表示每行固定有三个 float，分别对应 X、Y、Z：
```text
samples[0][2]：第 1 条采样的 Z 轴
samples[3][0]：第 4 条采样的 X 轴
```
const 表示函数不能通过这个参数修改输入。count 是行数，由调用者提供；函数不能自动判断传入的数组实际有多长，因此 count 不得超出真实行数。

bias[3] 是输出缓冲区。C 函数参数中的这种数组写法实际传递地址，调用者必须准备至少三个 float。

## 5. 两层循环为什么这样写
外层 i 依次选择采样时刻，内层 axis 遍历三个轴。sum[axis] += samples[i][axis] 就是在累加对应轴。

先把输入全部检查并累加，再计算三个均值到 next。最后才写 bias，保证遇到 NaN 等无效数据时不会只更新一半结果。

用 double 保存总和可以降低大量 float 相加的误差。输出仍使用 float，与后面的姿态样稿接口保持一致。

## 6. 如何连接四元数更新
每次收到角速度后，分别执行：
```c
corrected_x = measured_x - bias[0];
corrected_y = measured_y - bias[1];
corrected_z = measured_z - bias[2];
```
然后把 corrected 三轴值送入姿态更新。

测量值和零偏必须采用同一单位、同一轴定义。如果先以度/秒标定，就不能直接从弧度/秒读数中减去它。

本例使用批量数组便于理解；MCU 若不想保存全部采样，可以改成运行总和或在线均值，但必须仍保留采样数量和静止条件。

## 7. 验证、成本与局限
main 检查三个已知均值、去偏后的角速度，以及样本不足和 NaN 的拒绝行为。示例只用四条数据，目的在于方便手算；实际标定可采集数秒数据，再观察均值是否稳定。

算法本身时间 O(N)，额外工作存储 O(1)，调用者提供的输入数据占 O(N)。它只估计固定偏差，不校准比例因子和轴间误差，也不在线追踪温漂。
