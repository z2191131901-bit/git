# 69 超前滞后补偿：按频率调整控制器的增益与相位

配套代码：[超前滞后补偿.c](超前滞后补偿.c)。
本篇提供标准 C99 递推函数、频率响应检查和四组闭环模型仿真。
它是经典单输入单输出线性控制的入门示例，尚未实物验证。

## 1. 先理解为什么需要“补偿”

已有 PID 可以按比例、积分、微分来调整控制器。
超前和滞后补偿则换一个角度：分别观察不同频率信号经过控制器后，幅度和相位怎样变化。

- 超前补偿：在一段频率内提供正相位，并通常提高较高频率的增益。
- 滞后补偿：在一段频率内提供负相位；合理选择归一化增益时，可以提高低频增益。
- 两段串联：先处理瞬态响应，再结合低频精度要求进一步调整。

这里的“超前”不表示能知道未来的测量值。
它描述正弦稳态下输出与输入的相位关系，代码仍然只使用当前和过去的数据。

超前可能改善某个对象的响应，也会放大噪声与阶跃输入。
滞后可能减小某个对象的稳态误差，也可能使响应变慢或稳定裕度下降。
因此，本例用数据展示具体变化，不把这些方法理解成“一加上就全面变好”。

## 2. 使用统一的连续公式

~~~text
C(s) = K * (1 + Tz*s) / (1 + Tp*s)
~~~

| 符号 | 代码变量 | 含义与单位 |
|---|---|---|
| K | gain | 直流增益，单位为输出单位/输入单位；本例信号归一化 |
| Tz | zero_time | 零点时间常数，单位 s，要求不小于 0 |
| Tp | pole_time | 极点时间常数，单位 s，要求大于 0 |
| dt | dt | 固定采样周期，单位 s |
| x[k] | input | 本周期补偿器输入 |
| v[k] | output | 本周期补偿器输出 |
| b0、b1、a1 | 同名成员 | 离散递推系数 |

s 是连续系统传递函数里的变量，不是代码中的秒数。
对于 Tz>0，零点在 -1/Tz，极点在 -1/Tp。

当 Tz>Tp 时，两者之间出现正相位，是超前段。
当 Tz<Tp 时，两者之间出现负相位，是滞后段。
当 Tz=Tp 时，零极点抵消，整个环节等于比例 K。

直流输入变化无限慢，因此直流增益是 K。
在足够高的模拟频率下，增益趋近 K*Tz/Tp。
这两个极限是非常方便的检查条件。

## 3. 本例的两段参数

~~~text
超前：K=2，Tz=0.5 s，Tp=0.1 s
滞后：K=5，Tz=0.5 s，Tp=2.5 s
采样：dt=0.01 s，即 100 Hz
~~~

超前段的直流增益为 2，高频增益为 10。
滞后段的直流增益为 5，高频增益为 1。

因此，滞后段接在已有控制器之后，会使直流增益增加到原来的 5 倍，
而它自身的高频增益保持为 1。
这是本例选择 K=5 的原因；仅仅交换两个时间常数，不一定得到相同的低频增益设计。

两段串联后的直流增益为 2*5=10。
两段串联后的高频增益为 10*1=10。

## 4. 从传递函数推导到 C 递推

采用双线性变换，也叫 Tustin 变换：

~~~text
s = (2/dt) * (1-z^-1)/(1+z^-1)
~~~

z^-1 表示延迟一个采样周期。
将这个表达式代入连续公式并整理：

~~~text
C(z) = (b0+b1*z^-1)/(1+a1*z^-1)

b0 = K*(dt+2*Tz)/(dt+2*Tp)
b1 = K*(dt-2*Tz)/(dt+2*Tp)
a1 =   (dt-2*Tp)/(dt+2*Tp)
~~~

再把分母移到等式左边：

~~~text
v[k] + a1*v[k-1] = b0*x[k] + b1*x[k-1]
~~~

于是每个周期只需要：

~~~text
v[k] = b0*x[k] + b1*x[k-1] - a1*v[k-1]
~~~

代码没有矩阵求逆，也没有每个周期重新计算时间常数。
compensator_init 计算系数，compensator_step 只完成乘加并保存历史量。

特别注意最后一项是减去 a1*v[k-1]。
a1 本身可以为负数，不能凭感觉再改一次符号。

## 5. 手算前两个输出

使用超前段参数：

~~~text
分母 dt+2*Tp = 0.01+0.2 = 0.21

b0 = 2*(0.01+1)/0.21 =  9.619047619
b1 = 2*(0.01-1)/0.21 = -9.428571429
a1 =   (0.01-0.2)/0.21 = -0.904761905
~~~

假设之前的输入和输出都是 0，从当前开始一直给补偿器输入 1：

~~~text
v[0] = b0*1 + b1*0 - a1*0
     = 9.619047619

v[1] = b0*1 + b1*1 - a1*v[0]
     = 8.893424036
~~~

初始输出较大，之后最终回到直流输出 K*1=2。
这个手算是对补偿器单独施加恒定输入，不是闭环的第二个采样点。
闭环中的输入是误差，随着对象运动会继续变化。

如果执行器只能输出 ±2，这个初始输出将直接饱和。
本篇没有把线性补偿与饱和恢复混在一起，因此仿真报告控制量峰值，供你看到这种代价。

## 6. 相位是怎样产生的

把 s 换成 j*omega，omega 是模拟角频率，单位 rad/s：

~~~text
C(j*omega) = K*(1+j*omega*Tz)/(1+j*omega*Tp)

phase = atan(omega*Tz) - atan(omega*Tp)
~~~

超前段 Tz>Tp，第一项更大，因此相位为正。
滞后段 Tz<Tp，相位为负。

非退化情况下，最大相位变化的绝对值出现在：

~~~text
omega_middle = 1/sqrt(Tz*Tp)
~~~

本例超前最大相位约为 +41.810315°。
滞后中间频率的相位约为 -41.810315°。
二者的中间频率不同，因此串联后不能直接把这两个极值相加当作某个频点的总相位。

## 7. 数字频率与模拟频率不能直接混用

本例没有使用预畸变。
Tustin 会改变频率坐标，其准确映射为：

~~~text
theta = 2*atan(omega_analog*dt/2)
omega_analog = (2/dt)*tan(theta/2)
~~~

theta 的单位是 rad/sample。
如果把数字频率写成 rad/s，则 omega_digital=theta/dt。

频率较低时，两种频率近似相等；
接近奈奎斯特频率时，差异明显。
代码在映射后的频点比较连续公式与离散公式，避免用错误的坐标得出“离散化有误”。

另外，代码真的向递推函数输入余弦信号，
先等待暂态消失，再用整周期正弦、余弦投影恢复幅度与相位。
因此测试同时检查了差分递推和频域公式是否一致。

## 8. 四组控制器怎样公平比较

仿真对象为：

~~~text
tau * y' = -y + u
tau = 1 s
参考 r = 1
误差 e = r-y
初始 y = 0
~~~

y、r、u 都是归一化信号。
每个周期内 u 不变，采用精确的零阶保持离散公式：

~~~text
A = exp(-dt/tau)
y[k+1] = A*y[k] + (1-A)*u[k]
~~~

四组控制器分别是：

| 名称 | 从误差到执行器输入的路径 | 总直流增益 |
|---|---|---:|
| P | 2*e | 2 |
| lead | 超前段(e) | 2 |
| P+lag | 滞后段(2*e) | 10 |
| lead+lag | 滞后段(超前段(e)) | 10 |

对象、初始状态、参考、采样周期和仿真时长相同。
增益不同是控制器设计的组成部分，不能把结果解释成所有组在相同控制努力下的排名。

## 9. 实际运行结果怎样阅读

本例运行 60 s：

| 控制器 | 最终输出 | 最终误差 | t90/s | 调节时间/s | 最大绝对控制量 |
|---|---:|---:|---:|---:|---:|
| P | 0.666666667 | 0.333333333 | 0.760 | 1.300 | 2.000000 |
| lead | 0.666666667 | 0.333333333 | 0.590 | 1.630 | 9.619048 |
| P+lag | 0.909090909 | 0.090909091 | 0.710 | 2.340 | 2.015968 |
| lead+lag | 0.909090909 | 0.090909091 | 0.770 | 1.330 | 9.695846 |

t90 是首次达到“自身最终值的 90%”的采样时间。
调节时间是进入并在剩余仿真时间内保持在“自身最终值 ±2%”内的时间。
它们都不是达到参考值 1 的时间，因为这些控制器没有消除稳态误差。

可以直接看到：

1. 超前段让本组模型更早达到自身最终值的 90%，但调节时间反而更长。
2. 超前段的输出峰值明显增大，执行器能力要求更高。
3. 滞后段增大低频增益，使最终误差减小，但没有降到 0。
4. 两段串联的结果同时受增益、极点和零点影响，不能只看算法名字判断速度。

## 10. 为什么最终误差不会为零

对象直流增益为 1，控制器总直流增益为 Ktotal。
单位负反馈稳态满足：

~~~text
y = Ktotal*(1-y)

y = Ktotal/(1+Ktotal)
e = 1/(1+Ktotal)
~~~

Ktotal=2 时，y=2/3，e=1/3。
Ktotal=10 时，y=10/11，e=1/11。
这些理论值也作为仿真断言使用。

本篇的滞后段具有有限直流增益，不包含理想积分器。
若希望对恒定参考消除稳态误差，需要结合系统类型和内模条件重新设计，而不是无限增大 K。

## 11. 实际调用顺序

~~~c
Compensator lead, lag;
double error, middle, command;

/* 只在启动或有计划地重新配置时初始化。 */
compensator_init(&lead, 2.0, 0.5, 0.1, 0.01);
compensator_init(&lag, 5.0, 0.5, 2.5, 0.01);

/* 每 0.01 s 执行一次，实际应用必须检查返回值。 */
error = reference - measurement;
compensator_step(&lead, error, &middle);
compensator_step(&lag, middle, &command);
~~~

之后把 command 送给对象，再等待下一周期的新测量值。
不要每次循环都调用初始化，否则历史量被清零，动态补偿就消失了。
不要把一个实例同时用于两个独立通道，否则历史量会混在一起。

示例初始化把历史量清零，适合本篇“从静止开始”的实验。
在线切换参数、接管正在工作的执行器时，需要另外处理状态初始化与无扰切换。

## 12. 调参顺序与边界

先确认对象模型、采样周期和执行器限制。
然后根据希望改善的频率区间选择零点、极点，再调整增益。
若希望把超前相位集中在某个频率附近，可先检查 1/sqrt(Tz*Tp) 的位置。
只有补偿器自己的正相位，还不足以证明整个闭环稳定；还需要查看对象与采样延迟等环节。

本例只用一阶、无噪声、无延迟、无饱和的对象。
实际系统的柔性共振、测量噪声、死区、通信延迟等都可能改变结果。
尤其是超前段会提高高频增益，不能为了更快响应而不检查噪声和未建模动态。

本实现要求固定 dt。
采样周期改变后，需要重新计算系数，并考虑重置状态导致的输出跳变。
双精度数值量级过大时，初始化会拒绝非有限系数或无法与单位圆区分的极点。
