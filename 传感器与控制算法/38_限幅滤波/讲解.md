# 38 限幅滤波

配套代码：[限幅滤波.c](限幅滤波.c)。本例采用标准 C99，无第三方依赖。

## 1. 解决什么问题

距离传感器依次读到 10、11、100、12。100 可能是通信毛刺或测量异常，
希望拒绝这一点，而不是让它直接进入控制器。

这里“限幅”指限制相邻有效值的变化幅度，不是把数值限制到固定上下界。
固定上下界映射见第43篇；限制输出每秒变化速度见第42篇。

## 2. 状态和参数

| 名称 | 含义 |
| --- | --- |
| value | 最近一次被接受的数值 |
| initialized | 是否已经接受过第一个样本 |
| input | 当前原始测量 |
| max_delta | 相对最近有效值允许的最大差值 |

value、input、max_delta 必须使用相同单位，例如距离都使用 m。
Filter f={0,0} 表示还没有历史数据，第一次合法输入直接成为初值。

## 3. 公式与代码顺序

~~~text
未初始化：直接接受 input
已初始化且 abs(input-value) <= max_delta：接受
已初始化且 abs(input-value) > max_delta：拒绝，保留 value
~~~

先检查数值有限、门限非负；非法参数返回 -1。
然后比较与上次有效输出的差，不是与上次原始输入比较。
接受时更新 value，并把 initialized 设为 1，返回 1。
拒绝返回 0，不修改历史值。

这个返回值可以用于统计异常次数。不能把返回 0 理解成测量数值为零。

## 4. 手算

初值 10，max_delta=2：

| 输入 | 与有效值之差 | 结果 |
| --- | --- | --- |
| 11 | 1 | 接受，value=11 |
| 100 | 89 | 拒绝，value仍为11 |
| 13 | 2 | 等于门限，接受 |

这样毛刺不会污染下一次比较的基准。

## 5. 门限如何选择

结合正常变化速度与采样周期选择。
例如最大正常变化速度为 1 m/s、采样间隔 0.01 s，则正常变化量约为 0.01 m，
还要为测量噪声留出余量。固定门限隐含了相对稳定的采样周期。

门限太小会拒绝正常运动，太大则拦不住毛刺。
它不会平滑门限内的普通噪声，可根据需要与已有低通滤波组合。

## 6. 持续阶跃为什么会锁住

若 value=13，而真实值永久变为20，门限2会让之后每个20都被拒绝。
这不是代码坏了，而是“超限就拒绝”策略的固有限制。

示例明确演示了这个问题，并通过重新设置 initialized=0 接受新的水平。
实际系统应由上层确认传感器重新就绪或状态切换后复位，不能看到连续超限就无条件信任。
本例没有自动恢复策略。

## 7. 验证内容与成本

检查首样本、正常变化、单个毛刺、恰好等于门限、NaN、持续阶跃和显式复位。
每次更新 O(1)，只保存一个值和初始化标志。
