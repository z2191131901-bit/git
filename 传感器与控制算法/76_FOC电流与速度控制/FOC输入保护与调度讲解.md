# FOC输入、保护与调度补充讲解

本篇接着原来的[电流环与速度环讲解](讲解.md)读。原例讲清“电压怎样控制电流、电流怎样产生转矩”，这里补上实际接入前容易遗漏的输入处理和运行管理。

公共算法在[FOC输入与保护.h](../公共代码/FOC输入与保护.h)；运行调度与新增验证在[运行管理验证片段.h](运行管理验证片段.h)，由主C文件包含和运行。这个片段依赖主文件的电机模型与电流环，不单独编译。所有状态首次用 `{0}` 初始化。

## 1. 先分清四种单位

| 输入 | 单位 | 本例约定 |
| --- | --- | --- |
| 三相电流 | A | ADC计数需先由硬件适配层换算 |
| 编码器位置 | 机械rad | 方向与速度反馈一致 |
| 速度 | 机械rad/s | 不是电角速度，也不是rpm |
| 母线电压 | V | 实测反馈，不固定假设24V |

rpm转换：机械rad/s = rpm × 2π / 60。
电角速度 = 极对数 × 机械角速度。
把速度单位混用，会同时影响速度PI和电流环解耦项。

## 2. 为什么必须先校准电流零偏

假设实际电流为0，三路传感器却分别返回0.10、−0.05、0.02A。
直接做Clarke/Park，控制器会认为电机已经有电流，随后用电压“抵消”这个不存在的电流。

校准过程是：确认电流已经为零，禁止门极，采集64次，计算各路平均值。运行时分别做：

~~~text
校正电流 = 换算成A的采样值 − 该通道平均零偏
~~~

`foc_zero_sample` 要同时收到 gates_disabled 和 zero_confirmed。
禁止门极后电流可能仍通过续流路径流动，所以仅凭关PWM不能确认零电流。
不要在电机运行中自动校零，否则真实电流会被当成偏置。

增量均值的写法是：

~~~c
next.offset.a += (sample.a - next.offset.a) / next.count;
~~~

意思是“旧均值加上新样本对均值的修正”。无需保存64个样本。
只有输入和计算结果都有限时才写回状态，失败不会增加计数。
本例只处理零偏；电流增益误差、温漂、ADC饱和仍需另外校验。

## 3. 机械角度怎样变成电角度

~~~text
电角度 = 方向 × 极对数 × 机械角度 + 电角度零位偏置
~~~

本例极对数4：机械转π/8，对应电角度π/2。
方向只能选+1或−1；零位偏置以电rad填写，最后折回[0,2π)。

“编码器零位”通常不等于“转子磁场d轴零位”。
函数只执行已知参数的换算，没有实现通电对齐或自动辨识。
硬件接入时应先用安全的低电流流程确认相序、方向、极对数和零位。

调度例采用方向+1、偏置0，并使用理想机械编码器。
若修改方向，机械速度反馈必须同步改变符号，不能只改角度。

## 4. 速度目标为何加斜坡

直接把目标从0改成60rad/s，会让速度误差瞬间变大。
斜坡限制目标每次更新的最大变化：

~~~text
最大变化 = 加速度上限 × 速度环周期
~~~

本例速度环周期0.001s，加速度上限300rad/s²，所以每拍最多变化0.3rad/s。
从0到60的参考斜坡需要0.2s。实际速度是否跟得上，还取决于转矩、负载和电压。

代码把目标差值限制在±最大变化内，因此接近目标时不会跨过目标。
这只限制参考变化，并不保证机械加速度或电流绝对不超限。

## 5. 电流参考圆怎样限制

两个独立的±4A限幅会允许id=4、iq=4，电流矢量幅值达到约5.66A。
本例按圆限制：

~~~text
id² + iq² ≤ Imax²
~~~

实现采用d轴优先：
先将id限制到±Imax，再计算iq剩余余量。
例如id=3A、Imax=4A，iq最多为√7≈2.646A。

本例表贴式电机正常区设id=0，因此iq余量就是±4A。
如果以后加负id弱磁，q轴转矩电流余量会变小，速度环也需要接收这个动态限幅反馈。
当前调度没有弱磁，也没有处理可变id时的全部跨环约束。

参考圆约束不是实际过流保护。动态过程中的真实电流可以超出参考。

## 6. 故障位和锁存逻辑

| 故障 | 教学阈值或条件 |
| --- | --- |
| 欠压 | 母线<8V |
| 过压 | 母线>30V |
| 过流 | 任意相电流绝对值>6A |
| 超速 | 机械速度绝对值>240rad/s |
| 输入非法 | 非有限测量、非法配置或角度无效 |

阈值来自教学示例，不能直接照搬到你的电机和功率板。
边界值8V、30V、6A、240rad/s本身允许；超出才触发。
多项故障通过位掩码同时记录。

一旦故障，`faults |= active` 保留记录。
下一拍测量正常也不会自行恢复门极使能。
清除需要同时满足：reset=1、enable=0、当前检查健康。
运行中按reset不清故障；故障仍存在时停机复位也不清故障。

没有完成零偏校准时禁止启动，但等待校准本身不算故障。
编码器有效标志来自调用者；当前代码不检测“有限但已经过期”的角度。
实物应另加采样时间戳、通信超时和编码器一致性检查。

## 7. 关断与控制状态怎样分开

`gate_enable=0` 表示硬件适配层必须真正禁止功率驱动。
占空比50%只是零平均线电压的一种调制状态，不能代替关断。
占空比全0也不能作为各类驱动器的通用安全接口。

停机或故障时，`drive_clear` 清空：
电流PI积分、速度PI积分、速度斜坡、iq参考、分频计数与PWM缓存。
它保留电流零偏校准和故障位，避免停机后丢失诊断信息。

复位后仍保持停机；再次给enable才重新运行，参考从0逐步增加。
这是教学中的明确启动顺序，没有模拟停机后功率回路的高阻、续流或制动行为。
真实运行中的自动重启策略必须结合设备需求制定。

## 8. 内环电压不足为何要反馈给速度环

速度PI输出iq参考，即使iq参考没有超过4A，母线电压也可能已经无法支持它。
因此，速度PI自身的输出限幅不一定能识别内环饱和。

电流环新增两个反馈量：
`voltage_limited` 表示SVPWM电压圆限幅；
`q_voltage_deficit = 原始vq请求 − 实际vq`，单位V。

外环用上一电流拍的反馈。
如果速度误差与q轴电压缺额同号，继续积分通常会增加当前方向的需求，本例冻结该次速度积分。
如果反号，仍允许积分，帮助退出饱和。
函数只支持PI，要求Kd=0；电流环自己的矢量反算仍保留。

这是一种条件积分策略，并非所有工况都更优。
测试先在8V下要求80rad/s，1s后恢复24V，同时把目标降到20rad/s。
恢复后的速度绝对误差积分如下：

| 外环策略 | 恢复误差积分，rad |
| --- | --- |
| 仅外环自身输出抗饱和 | 1.295741631 |
| 再接内环电压限幅反馈 | 1.381233178 |

两种策略最终均到19.999999rad/s。
本工况额外冻结略增误差，说明“减少积分积累”不等于“任意目标变化都恢复更快”。
测试核对有限结果、确实发生电压限幅及最终收敛，不断言某种策略必胜。
应用时应结合母线变化、负载、正反转和目标变化比较，而不是只看一个指标。

## 9. 一次调度的执行顺序

1. 把电流减去零偏，把机械角度换算为电角度。
2. 每个电流周期先检查输入、母线、电流和速度，更新故障锁存。
3. 不允许驱动时清空控制状态并返回，硬件层落实门极禁止。
4. 每10拍更新一次速度参考斜坡和速度PI。
5. 对dq电流参考做圆限幅。
6. 更新电流PI、解耦、逆Park和SVPWM，保存内环饱和反馈。
7. 硬件层在规定时刻更新PWM；下一拍重新采样。

速度环1kHz、电流环10kHz不是通用最佳频率，实际受电机参数、PWM和采样条件影响。
本例没有实现ADC触发、PWM影子寄存器更新、RTOS任务或中断。

## 10. 新增验证具体检查什么

校准验证注入已知偏置与一整周期余弦噪声，校正后恢复1、−0.5、−0.5A。
非法采样以及未确认零电流时不会增加校准计数。
角度验证检查极对数、方向、零位和非法参数。
斜坡验证检查目标收敛、反向变化与NaN拒绝。
参考圆验证用3-√7-4关系独立核对。

逐类注入欠压、过压、过流、超速、角度无效；检查故障锁存、运行中拒绝复位、停机健康复位。
另检查NaN母线。
完整闭环给测量加入三路偏置，再校正并使用机械角度换算，运行0.8s：
目标60rad/s，最终59.999498rad/s。

随后注入过流，检查门极使能关闭、积分清零、校准保留。
测量恢复正常不自动重启；停机复位、再使能后第一拍参考0.3rad/s。
验证代码依靠assert检查，请不要定义NDEBUG。

软件模型通过不能证明功率板安全。
