# FOC入门：先看懂怎样让电机按目标转，再读代码

[打开配套代码](FOC电流与速度控制.c) · [返回学习入口](../新手从这里开始.md)

FOC中文常叫磁场定向控制。它控制的是电机中的电流方向与大小。
本篇先用具体问题解释各模块的作用。读懂整体过程后，再去看矩阵和电机方程。

第一遍读到第8节，能说出“速度目标→电流目标→电压→电机”的顺序即可。
[进阶原理与模型验证](进阶原理与模型验证.md)保留原来的完整推导；
[输入保护与调度讲解](FOC输入保护与调度讲解.md)讲校准、故障与停机管理。

## 1. 为什么先学PID，再学FOC

假设你想让电机保持某个速度。负载突然变重，电机会减速。
速度控制器看见实际速度低于目标，应该要求电机产生更大的转动力量。

这种让电机旋转的作用叫转矩。
在本例的永磁电机中，合适方向的电流越大，转矩通常越大。
所以速度控制器可以先给出“需要多少电流”，电流控制器再决定“需要施加多少电压”。

这就有了两个闭环：

~~~text
速度控制器：目标速度 − 实际速度 → 所需电流
电流控制器：目标电流 − 实际电流 → 所需电压
~~~

本例采用PI，也就是PID里的P和I，D设为0。
如果还不能手算一次PI，先读[PID入门](../23_PID/讲解.md)第1～7节。

## 2. 我们控制的电机是什么样

本例是表贴式永磁同步电机，可以先想成：

- 固定部分叫定子，有三相绕组，代码用a、b、c表示。
- 转动部分叫转子，带有永磁磁场。
- 三相绕组通电形成磁场，与转子磁场作用，产生转矩。

三相电流随转子运动不断变化。
同一个转矩需求下，不能始终给三相固定不变的电流值，否则磁场方向跟不上转子。

FOC会根据转子现在的位置，换一种坐标表示电流。
换好坐标后，原本随角度变化的三相量，更容易用PI控制。

“同步”涉及磁场与转子运动的关系；第一遍不必从电机设计推导开始。
代码只模拟这一类电机的教学参数，其他电机不能直接套全部参数。

## 3. 先认识输入与输出

| 控制器需要知道 | 为什么需要 |
| --- | --- |
| 三相电流a、b、c，单位A | 知道当前实际电流 |
| 转子电角度，单位rad | 知道电流要相对哪个方向解释 |
| 机械角速度，单位rad/s | 与速度目标比较，并计算电压补偿 |
| 母线电压，单位V | 知道驱动能提供多大的电压 |
| 目标速度或dq电流目标 | 知道你希望电机怎样运行 |

母线电压就是逆变器供电侧的直流电压，例如24V。
逆变器是用功率开关把直流电源变成电机所需三相驱动的电路。

最终输出是三相PWM占空比，不是直接输出角度。
占空比0.75代表一段PWM周期里该桥臂上管对应的开通比例为75%。
真实硬件还需要互补驱动、死区和保护，这些由硬件层实现。

## 4. d和q为什么会出现：把坐标轴跟着转子转

先想象你在地面上观察一个转动的轮子，轮子上的箭头一直改变方向。
如果你跟着轮子一起转，这个箭头相对你就不再到处转。

FOC也做类似的“换观察角度”：
将电流从固定坐标换到随转子磁场转动的坐标。

~~~text
三相a、b、c
    ↓ Clarke：用固定的两个坐标表示主要电流分量
固定坐标alpha、beta
    ↓ Park：根据转子电角度，把坐标轴转过去
转动坐标d、q
~~~

alpha读作阿尔法，beta读作贝塔。它们是固定坐标的两个方向。
d轴在本例中沿转子永磁磁场方向，q轴与它垂直。
id和iq只是同一电流在新坐标下的分量，不是另外安装的两根绕组。

本例正常区令id目标为0，用iq主要控制转矩。
这依赖本例的电机类型与坐标约定；弱磁或凸极电机还会有其他策略。

为什么要转过去？理想稳定运行时，dq目标可以近似保持常数。
PI更容易跟踪“恒定的2A”，而不必直接追随三相各自不断变化的波形。

## 5. 只算一组简单数字，确认坐标不是魔法

取三相电流：

~~~text
ia=0A，ib=1.7320508A，ic=−1.7320508A
~~~

三相和为0。本仓库采用的变换得到：

~~~text
alpha = (2ia−ib−ic)/3 = 0
beta = (ib−ic)/√3 ≈ 2A
~~~

转子电角度为0时，转动坐标与固定坐标对齐，所以：

~~~text
id = alpha = 0A
iq = beta ≈ 2A
~~~

读懂这一组即可。其他角度需要乘sin和cos：
这些函数用来计算旋转后在两个轴上的投影，输入角度用rad。

[电机坐标变换](../73_电机坐标变换/讲解.md)有完整公式与其他角度的验证。
先知道每次变换的目的，再去读公式，会更容易跟上。

## 6. 整个控制链按顺序读

~~~mermaid
flowchart TD
    A[速度目标与实际速度] --> B[速度PI：给出iq目标]
    C[实测三相电流] --> D[Clarke和Park：得到id与iq]
    E[转子电角度] --> D
    B --> F[电流PI：给出vd与vq]
    D --> F
    F --> G[逆Park：换回固定坐标电压]
    G --> H[SVPWM：计算三相占空比]
    H --> I[电机收到驱动]
    I --> C
    I --> A
~~~

速度PI输出iq参考；本例把它限制到±4A。
“参考”就是目标值，iq_ref和iq_reference都是这个意思。

电流PI将目标和实测id、iq比较，得到电压请求vd、vq。
逆Park把转动坐标中的电压换回固定坐标，方便驱动使用。

SVPWM是空间矢量PWM。入门时先把它看作：
“输入要求的固定坐标电压和母线电压，输出三相占空比”。
[空间矢量PWM](../74_空间矢量PWM/讲解.md)再解释怎样计算。
它不能产生超过电源能力的电压，因此会限制过大的请求。

## 7. 跟着源码手算一次电流控制

找到FOC电流与速度控制.c中的check_model_and_current。
测试令电机锁住不转，初始电流0，id目标0，iq目标2A，母线24V。
“锁轴”指外部夹具让转子无法转动，不代表断开电流。

本例电流PI的Kp=1.8，Ki=720，周期dt=0.0001s。
最初I为0，速度也为0，速度相关补偿为0。

~~~text
q轴误差 = 2−0 = 2A
本拍q轴电压请求 = 1.8×2 + 旧I = 3.6V
下一拍使用的I = 0 + 720×2×0.0001 = 0.144V
~~~

注意：这份电流环先算本拍输出，再更新下一拍的积分。
PID入门里公共PID函数先试算新积分再算输出，时序不同。
不能把两段代码的手算顺序混用。

3.6V没有超过24V母线下的本例线性电压范围，因此不会触发电压限幅。
theta=0时，逆Park给出alpha电压0、beta电压3.6V。
SVPWM将它变成占空比，模型接收到对应的平均电压，电流逐步接近2A。

这就完成了最短的一条理解路径：
误差2A → 要求电压3.6V → 电流开始变化 → 下一拍重新测量。

## 8. 两个循环为什么速度不同

电流通常变化得比机械速度快，电流环需要更频繁更新。
本例每0.0001s算一次电流，也就是10kHz；
每10个电流周期算一次速度，也就是0.001s、1kHz。

~~~text
第0拍：算速度环，算电流环
第1～9拍：沿用最近的电流目标，只算电流环
第10拍：再算速度环，算电流环
~~~

“环”是持续重复的控制过程，不是某个C语法关键字。
这些频率只是本例参数，不是所有电机都应使用的固定值。

## 9. 角度和速度最容易混在哪

电机机械转一圈，磁场的电角度可能经历多圈。
本例极对数为4，也就是8个磁极，因此：

~~~text
电角度 = 4 × 机械角度 + 电角度零位偏置
电角速度 = 4 × 机械角速度
~~~

机械转90度，本例对应电角度360度。
计算sin和cos时用弧度：180度=π rad，360度=2π rad。

机械速度80rad/s约等于764rpm。
代码中目标80表示80rad/s，不是80rpm，也不是80度。
MotorState.speed保存机械角速度，MotorState.theta保存电角度。

编码器机械零位通常需要额外标定，才能知道磁场d轴方向。
输入补充函数只换算已知方向、极对数和零位，没有自动标定。

## 12. 为什么还需要输入校准和保护

真实电流传感器即使没有电流，也可能读到0.1A，这叫零偏。
补充代码在确认电流为零且门极禁止时采样，运行时减掉零偏。

本例还加入速度目标斜坡：从0逐步提高，而不是一下跳到60。
dq电流参考圆限制目标电流大小；它不能保证实际电流绝对不超限。

软件检查欠压、过压、实际相电流超限、超速和非法输入。
触发后保留故障记录、禁止使能并清空控制积分。
恢复正常也不自动重启，需要停机且测量健康时复位，再使能。
实际门极关闭仍由硬件层落实。

完整顺序见[FOC输入保护与调度讲解](FOC输入保护与调度讲解.md)。
电脑验证没有模拟开关纹波、真实采样时刻或功率板硬件故障关断。

## 13. 三个不写代码也能做的自测

**题1：目标速度大于实际速度，会先改变哪个目标？**
按本例正向约定，速度PI通常增加iq目标，让电机请求更大转矩。
它不是直接把速度误差送进Clarke。

**题2：为什么还要实测电流，不能只相信iq目标？**
目标是控制器希望达到的值；实际电流受电压、转速和对象动态影响。
电流环通过反馈纠正两者差距。

**题3：电流目标限制到4A，实际电流是否一定小于4A？**
不一定。原实验峰值约4.007629A，所以需要实际电流检测与保护。
教学参考限幅不能代替功率器件保护。

## 14. 下一遍怎样继续学

建议顺序：PI → 电流与转矩 → Clarke/Park → 逆Park与SVPWM → 两环调度 → 保护。
然后再去看电机微分方程、解耦前馈、内外环抗饱和及弱磁。

本例只实现已注明的教学范围，没有无传感器启动、弱磁或MTPA。
你不需要第一遍就掌握全部公式，但要先分清每个模块接收什么、输出什么。
