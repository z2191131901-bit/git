# 72 输入整形抑振：ZV与ZVD

[配套代码](输入整形抑振.c) · [本批验证记录](../抑振与电机控制基础验证.md)

## 1. 先看要解决的问题

给柔性机构一个突然变化的位置目标，机构可能先走到附近，再来回振动。
简单减慢运动往往也能减少振动，但可能降低效率。
输入整形则利用已知振动频率，把原指令拆成几个带延迟、带权重的副本。

本篇讨论一个欠阻尼二阶模态。
它可作为理解机械残振的模型，不等于直接完整描述某一台机械臂或打印机。
对于带闭环伺服的机构，需要关注从指令到输出的等效振动模态。

## 2. 输入整形到底处理哪个量

~~~text
原目标r[k] → 输入整形器 → 整形后目标u[k] → 对象 → 实际输出y[k]
~~~

整形器没有读取y，不依靠误差反馈。
它修改的是命令，和第20篇对信号频段进行抑制的陷波滤波应用位置不同。
本例也没有额外串接PID。

算法的基本公式：

~~~text
u[k]=A0*r[k-N0]+A1*r[k-N1]+A2*r[k-N2]
~~~

ZV只使用两项，ZVD使用三项。
权重之和为1，所以恒定目标经过全部延迟后仍保持原值。

## 3. 二阶模态与单位

仿真对象为：

~~~text
y''+2*zeta*wn*y'+wn²*y=wn²*u
wn=2*pi*fn
wd=wn*sqrt(1-zeta²)
~~~

| 参数 | 含义 | 本例 |
| --- | --- | --- |
| fn | 无阻尼自然频率，Hz | 5 |
| wn | 自然角频率，rad/s | 2*pi*5 |
| zeta | 阻尼比，无量纲 | 0.05 |
| wd | 阻尼振动角频率，rad/s | wn*sqrt(1-zeta²) |
| dt | 固定采样周期，s | 0.001 |
| y、u | 输出与目标 | 同单位归一化量 |
| v | y的变化率 | 输出单位/s |

不能把测得的阻尼振动频率直接无条件等同于fn。
本模型二者关系为fd=fn*sqrt(1-zeta²)。
对于很小的阻尼，两者接近。

## 4. ZV：让第二次激励抵消第一次的残振

欠阻尼响应经过半个阻尼振动周期后，振动相位反转：

~~~text
T=pi/wd
K=exp(-zeta*pi/sqrt(1-zeta²))
~~~

K描述这半周期内的自然衰减。
如果第一脉冲权重为A0，第二脉冲需要匹配衰减后的振动幅值：

~~~text
A1=K*A0
A0+A1=1
~~~

解得：

~~~text
ZV时刻：[0,T]
ZV权重：[1/(1+K), K/(1+K)]
~~~

两次命令增量都是正的，但它们激起的振动在适当时刻具有相反相位。
不能把“抵消振动”理解为必须给出正负相反的目标。

## 5. ZVD：多一项，改善频率误差附近的效果

把两个相同的ZV整形器串联，等效权重来自卷积：

~~~text
ZVD时刻：[0,T,2*T]
ZVD权重：[1,2*K,K²]/(1+K)²
~~~

在理想连续延迟、模型匹配条件下，设计频率处的残振零点重复，
使它在设计频率附近对小幅频率失配更不敏感。
代价是最后一个脉冲更晚到达。

这不是所有失配情况下都无残振的保证。
本例还把连续延迟取整到采样拍，因此即使频率匹配也有小残振。

## 6. 手算本例的系数和延迟

fn=5Hz，zeta=0.05时：

~~~text
K≈0.854467893
T≈0.100125235 s

ZV：
A0≈0.539238239
A1≈0.460761761

ZVD：
A0≈0.290777878
A1≈0.496920721
A2≈0.212301401
~~~

以dt=0.001秒运行，半周期对应100.125235拍。
代码四舍五入成N=100：

~~~text
ZV延迟：[0,100]拍
ZVD延迟：[0,100,200]拍
~~~

从0突然给目标1时，ZVD的实际命令是：

| 拍数k | 整形后命令 |
| --- | ---: |
| 0～99 | A0≈0.290777878 |
| 100～199 | A0+A1≈0.787698599 |
| 200及以后 | A0+A1+A2=1 |

每个阶跃增量经过机构动力学后产生自己的响应，再叠加成总输出。
输入整形不是简单把速度或加速度限制到某个值。

## 7. 对应到C结构体

Shaper包含三组权重、三个延迟、脉冲数量、写入位置和历史数组。
count为1表示原指令，2表示ZV，3表示ZVD。

初始化清空整个历史，表示启动前r[k]=0。
它不会自动读取真实机构的当前位置。
如果在非零稳态命令下启用，需要另行初始化历史或安排平滑切换。

history有2048个double，常见平台约占16KiB。
这是便于教学的固定容量；移植小型MCU时应按最大延迟裁剪。
仿真函数同时创建两个实例，实际使用不需要保留这种测试布局。

## 8. 环形历史数组怎么取延迟

write指向当前输入即将写入的位置。
延迟N拍的输入位于：

~~~text
index=(write+HISTORY-N)%HISTORY
~~~

由于当前输入尚未写入，零延迟项直接使用参数input。
延迟项读取数组中的旧输入。

更新顺序是：

1. 用当前输入和旧历史计算整形结果。
2. 检查结果是否有限。
3. 把当前输入写入history[write]。
4. 将write前移一格，末尾后绕回0。
5. 写回output。

不能把历史数组每次都清零，也不能每拍重新初始化。
传入NaN时不移动write、不改历史、不写输出。

## 9. 为什么仿真使用精确对象更新

每个采样周期内保持u不变，二阶系统可用解析状态转移更新y、v。
这样可以避免简单欧拉积分自身的数值误差掩盖输入整形的效果。

程序还用另一条计算路径复核：

~~~text
总输出 = sum(Aj * 单位阶跃响应(t-tj))
总速度 = sum(Aj * 单位阶跃响应导数(t-tj))
~~~

阶跃响应使用实际对象频率，而权重和延迟仍由设计频率5Hz确定。
匹配频率和5.5Hz失配情况下，原指令、ZV、ZVD均与该解析叠加一致。

## 10. 残振为什么不能只看一个位置误差

某一时刻y刚好过目标，不代表振动消失；此时速度可能还很大。
最后一个命令增量已生效后，最终目标为1，定义e=y-1。

本例用位置和速度恢复当前衰减正弦包络：

~~~text
residual=sqrt(e²+((v+zeta*wn*e)/wd)²)
~~~

后续没有新的指令变化时，该包络按exp(-zeta*wn*t)衰减。
这个指标是振动幅值，不是IAE，也不是全程最大超调。

三组都在t=0.201秒比较，即最长ZVD延迟之后再走一拍。
不拿各自不同的完成时刻混着比较。

## 11. 实际运行结果

| 真实自然频率 | 原指令残振 | ZV残振 | ZVD残振 |
| --- | ---: | ---: | ---: |
| 5Hz，匹配 | 0.730169561 | 0.001548947 | 0.000003286 |
| 5.5Hz，偏高10% | 0.707476049 | 0.118796356 | 0.019947777 |

ZV的最后一个命令增量延迟0.100秒，ZVD为0.200秒。
ZVD在这组失配中留下更小残振，但增加了命令延迟。
各组对象的自然衰减、采样周期、比较时刻和单位阶跃目标保持一致。

本例仍有延迟量化误差，所以匹配模型的数值也没有写成严格零。

## 12. 调参与限制

先估计主导模态频率与阻尼，再选dt和允许的指令延迟。
若频率估计不稳定，可比较ZVD的失配容忍与增加的延迟是否值得。

本程序只支持0<=zeta<1。
为保证延迟数组可容纳完整ZVD，三种模式统一限制最大延迟范围。
不支持多个模态、分数拍延迟、在线重设时的无扰切换或执行器饱和。

目标轨迹若还受速度、加速度或行程约束，需要与轨迹规划一起检查。
不要把本例阶跃实验直接当成硬件运动指令。
