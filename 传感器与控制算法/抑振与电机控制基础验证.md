# 抑振与电机控制基础验证

2026年9月27日在Windows / MinGW-w64 GCC 8.1环境验证。
本批新增第72～75篇，累计 **75个独立可运行C示例**，全部编译与运行通过。

## 1. 复现方法

在仓库根目录执行：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1
~~~

编译选项：-std=c99 -Wall -Wextra -Werror -pedantic，链接数学库。
脚本在系统临时目录建立ASCII编译副本，处理旧版MinGW中文include路径问题。
原中文源文件保持在仓库；构建产物不提交。
assert必须启用，不能定义NDEBUG；本例的验证调用写在assert内。
ExecutionPolicy Bypass仅作用于本次PowerShell进程。

新增公共文件[电机坐标变换.h](公共代码/电机坐标变换.h)，由第73～75篇复用。
各篇都包含独立中文讲解、单位约定、公式到代码的对应、手算或解析核对和范围说明。
本批未接入实际电机、逆变器或机械机构。

## 2. 输入整形抑振

[代码](72_输入整形抑振/输入整形抑振.c) · [讲解](72_输入整形抑振/讲解.md)

设计自然频率5Hz、阻尼比0.05、dt=0.001秒。
半阻尼周期0.100125235秒取整为100拍；ZV最后延迟0.100秒，ZVD为0.200秒。
三组均从静止开始接受单位阶跃，并在同一时刻0.201秒比较。

| 真实自然频率 | 原指令残振包络 | ZV残振包络 | ZVD残振包络 |
| --- | ---: | ---: | ---: |
| 5Hz | 0.730169561 | 0.001548947 | 0.000003286 |
| 5.5Hz | 0.707476049 | 0.118796356 | 0.019947777 |

残振由位置、速度一起计算，不是某个位置过零点的误差。
对象使用精确零阶保持更新；还与延迟阶跃解析响应叠加独立交叉验证。
匹配与失配的六种组合中，位置误差小于1e-11、速度误差小于1e-10。

其他检查：脉冲权重、权重之和、延迟位置、环形数组多次绕回、非有限输入和非法配置。
匹配频率时仍有整数拍量化误差；ZVD增加指令延迟，不代表免费提高响应速度。
仅单个欠阻尼模态，无执行器饱和、多模态或分数拍延迟。

## 3. 电机坐标变换

[代码](73_电机坐标变换/电机坐标变换.c) · [讲解](73_电机坐标变换/讲解.md)

采用幅值不变的Clarke和Park，保留零序，theta单位rad。
手算输入abc=(2,-1,-1)得到alpha/beta=(2,0)，转轴90度后dq=(0,-2)。

扫描721个角度采样，同时检查平衡旋转三相、不平衡三相、逆变换和平方和恒等式。

~~~text
最大三相往返误差：6.66e-16
最大平方和恒等式误差：2.66e-15
~~~

另检查纯零序、角度偏差导致的q轴符号、NaN和空输出指针。
这些是数学变换精度，没有包含传感器误差或转子位置估计误差。
平方和关系包含3/2与零序系数，不能把幅值不变与功率不变变换混用。

## 4. 空间矢量PWM

[代码](74_空间矢量PWM/空间矢量PWM.c) · [讲解](74_空间矢量PWM/讲解.md)

两电平三相平均调制，母线12V。
采用最大最小值公共偏置，并把电压矢量保持方向地限制到Vdc/sqrt(3)内。

~~~text
alpha=6V、beta=0：
duty=(0.875,0.125,0.125)

内切圆半径：6.928203230V
最大电压矢量重建误差：3.2e-15V
~~~

验证360个角度与4种幅值，共1440组请求。
从占空比反推平均桥臂电压，再核对alpha/beta及线电压。
另核对零请求、30度切点、超出圆半径1.8倍时的缩放和无效母线电压。

本例只用六边形内切圆，不实现过调制；
没有输出真实定时器波形、死区、最小脉宽或电流采样时序。
占空比端点在数学上合法，不代表所有硬件都能直接使用。

## 5. 数字锁相环

[代码](75_数字锁相环/数字锁相环.c) · [讲解](75_数字锁相环/讲解.md)

采用SRF-PLL，输入为Clarke产生的正交alpha/beta。
dt=0.0005秒，名义50Hz，频率范围40～70Hz，归一化鉴相；
小信号自然频率参数10Hz，阻尼比1/sqrt(2)。

| 窗口 | 时间范围/秒 | 最大相位误差/rad | 最大频率误差/Hz |
| --- | --- | ---: | ---: |
| 初始捕获后 | [0.4,0.5) | 1.26033078e-8 | 7.09192349e-8 |
| 0.4rad相位跳变后 | [0.9,1.0) | 7.13380666e-9 | 4.04105762e-8 |
| 50→55Hz后 | [1.4,1.5) | 8.21186852e-9 | 9.01060915e-8 |
| 幅值2→0.4后 | [1.9,2.0) | 0（本机打印值） | 1.42108547e-14 |
| 输入丢失再恢复后 | [2.3,2.5) | 0（本机打印值） | 1.42108547e-14 |

最终频率55.000000000Hz，信号丢失期间保持运行200拍。
统计窗口留出了暂态恢复时间，不是全程最大误差，也不证明全局捕获。

另有首拍手算、频率上/下限、条件积分抗饱和、低幅值保持、NaN和无效初始化检查。
失去信号期间真实频率刻意保持不变；算法只按最近频率推进，并没有新的真实相位信息。
信号为无噪声、平衡三相，没有验证谐波、不平衡或真实硬件精度。
