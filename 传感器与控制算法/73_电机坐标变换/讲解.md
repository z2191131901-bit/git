# 73 电机坐标变换：Clarke、Park与逆变换

[验证示例](电机坐标变换.c) · [实际算法函数](../公共代码/电机坐标变换.h) · [本批验证记录](../抑振与电机控制基础验证.md)

## 1. 为什么电机控制要换坐标

三个电流传感器给出a、b、c三相瞬时电流。
电流一直变化时，直接分别控制这三个量不容易看清它们与转子的关系。

Clarke把三个量表示为静止的alpha、beta和零序；
Park再把alpha、beta表示到跟随角度theta旋转的d、q轴上。
合适的旋转角度能使平衡正弦量在新坐标中变成常数，便于后续使用PI。

这一步只是数学表示变化，没有自动产生控制效果，也没有估算theta。
电流环、转子位置获取和PWM都需要另外的模块。

## 2. 先统一约定，再看公式

本篇固定采用：

| 项目 | 约定 |
| --- | --- |
| 相序 | a、b、c |
| alpha轴 | 与a相轴重合 |
| beta轴 | 相对alpha轴逆时针90度 |
| d轴 | 相对alpha轴逆时针旋转theta |
| q轴 | 相对d轴逆时针90度 |
| theta单位 | 弧度rad，不能直接传角度数值 |
| 缩放方式 | 幅值不变，不是功率不变 |
| 输入单位 | 三路相同，例如A；输出保持同一种物理单位 |

例如90度必须写成pi/2，而不是90。
电机FOC通常需要电角度；机械角度与电角度一般还涉及极对数和零位偏置。
本篇不替调用者计算这些换算，也不假定传入机械角就能直接使用。

## 3. Clarke公式：为什么多一个zero

~~~text
alpha = (2*a-b-c)/3
beta  = (b-c)/sqrt(3)
zero  = (a+b+c)/3
~~~

对于平衡三相，a+b+c=0，alpha会简化成a。
但本篇保留完整公式，因此也能处理三个任意有限瞬时数值。

零序保存三路共同的部分。
若a=b=c=1，那么alpha=beta=0，zero=1。
只保存alpha和beta会把这组三相输入误认为全零，无法再恢复原数据。

零序可以被数学表示，不代表三线制电机能够独立驱动零序电流。
测量偏置或接线问题也可能让测得的三相之和不为零，应结合硬件解释。

## 4. Park公式：旋转的是坐标轴

~~~text
d =  alpha*cos(theta)+beta*sin(theta)
q = -alpha*sin(theta)+beta*cos(theta)
~~~

代码中的cs、sn分别是cos(theta)、sin(theta)。
zero不受平面旋转影响，直接复制。

负号非常重要。
若真实矢量领先估计d轴，它的q应为正；
如果估计角度超过真实角度，q会变负。
第75篇锁相环正是利用这个符号纠正相位。

## 5. 手算一组数

输入：

~~~text
a=2，b=-1，c=-1
~~~

Clarke结果：

~~~text
alpha=(4+1+1)/3=2
beta=(-1+1)/sqrt(3)=0
zero=(2-1-1)/3=0
~~~

当theta=0：

~~~text
d=2，q=0
~~~

当theta=pi/2：

~~~text
d=2*0+0*1=0
q=-2*1+0*0=-2
~~~

物理矢量仍指向原来的alpha方向。
只是新d轴转了90度，因此它在新q轴上表现为负值。
代码用断言核对这个容易写错的符号。

## 6. 为什么平衡交流量能变成常数

令相电流峰值为I：

~~~text
a=I*cos(theta)
b=I*cos(theta-2*pi/3)
c=I*cos(theta+2*pi/3)
~~~

代入Clarke：

~~~text
alpha=I*cos(theta)
beta=I*sin(theta)
zero=0
~~~

再用同一个theta做Park：

~~~text
d=I*(cos²(theta)+sin²(theta))=I
q=0
~~~

代码设置I=3，扫描721个角度采样，检查d始终接近3、q接近0。
这里3是相电流峰值，不是有效值；对应正弦有效值为3/sqrt(2)。

若用于Park的角度比真实角度多delta：

~~~text
d=I*cos(delta)
q=-I*sin(delta)
~~~

示例取delta=0.1rad，独立检查q=-3*sin(0.1)。
因此位置传感器的零位偏差会把原本的d、q分量混到一起。

## 7. 逆变换怎么恢复三相

逆Park：

~~~text
alpha=d*cos(theta)-q*sin(theta)
beta =d*sin(theta)+q*cos(theta)
~~~

逆Clarke：

~~~text
a=alpha+zero
b=-alpha/2+sqrt(3)*beta/2+zero
c=-alpha/2-sqrt(3)*beta/2+zero
~~~

同一时刻的正变换和逆变换必须使用同一theta和同一缩放约定。
第74篇用逆Clarke把目标电压矢量转成三相电压请求。

## 8. 幅值不变，不代表平方和直接不变

本例满足：

~~~text
a²+b²+c² = (3/2)*(d²+q²)+3*zero²
~~~

所以不能直接用a²+b²+c²=d²+q²作为测试。

当电压、电流都用本篇约定变换时：

~~~text
瞬时功率 = (3/2)*(vd*id+vq*iq)+3*vzero*izero
~~~

这里的3/2来源于坐标缩放。
别把其他资料里的功率不变变换系数混进本文件。

测试既检查往返恢复，也检查上面的平方和恒等式。
前者能发现逆公式问题，后者能发现缩放遗漏；另有手算和旋转三相检查防止正反公式共同写错。

## 9. 怎样阅读和调用C函数

公共头文件有三个结构体：MotorAbc、MotorAb0、MotorDq0。
它们分别对应三相、静止坐标和旋转坐标。

~~~c
MotorAbc current = {2.0, -1.0, -1.0};
MotorAb0 stationary;
MotorDq0 rotating;
double electrical_angle = 0.0;

if (!motor_clarke(current, &stationary)) {
    /* 输入无效：交给本工程的故障处理逻辑。 */
}
else if (!motor_park(stationary, electrical_angle, &rotating)) {
    /* 角度或计算结果无效。 */
}
else {
    /* rotating.d、rotating.q可送给后续控制器。 */
}
~~~

&stationary表示把输出变量的地址交给函数。
函数先计算局部变量next，只有成功才执行*out=next，写回完整结果。
返回0时输出保持旧值，调用者不能将旧值误当成新测量。

这些变换没有历史状态，不需要dt，也不需要每次积分。
正弦、余弦可在实际MCU中改成查表或硬件加速，但必须重新检查精度和角度范围。

## 10. 编译与边界

仓库根目录执行：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 电机坐标变换.c
~~~

必须保留公共头文件，保持assert启用。
包含平衡/不平衡输入、纯零序、负角度、多圈角度、非法角度和输入检查。
过大的浮点输入导致溢出时会返回失败。

本例未实现两电阻采样重建、电流零偏校准、采样同步或传感器故障诊断。
