# 75 数字锁相环：同步旋转坐标系SRF-PLL

[配套代码](数字锁相环.c) · [坐标变换](../73_电机坐标变换/讲解.md) · [本批验证记录](../抑振与电机控制基础验证.md)

## 1. 锁相环想知道什么

给定一个旋转的周期信号，锁相环希望估计它的相位和频率。
估计相位可用于同步坐标变换，估计频率可描述信号旋转速度。

本篇采用同步旋转坐标系PLL，也叫SRF-PLL。
它接收alpha、beta两个正交分量，示例由平衡三相量经Clarke生成。

只有单条正弦波时，不能把beta随便设成0直接套用。
需要先构造正交分量，例如另外设计SOGI等模块。
本篇没有实现单相正交信号发生器，也不是电机转子无传感器观测器。

## 2. 三个环节组成一个闭环

~~~text
alpha/beta
   ↓ 归一化与Park变换
q轴相位误差
   ↓ PI
估计角频率omega
   ↓ 对时间积分
估计相位theta
   └──────── 回到Park变换
~~~

Park把输入投影到估计角度决定的d、q轴。
如果估计角度与真实角度相同，信号沿d轴，q接近0。

## 3. 鉴相误差的符号必须一致

设真实相位为phi，输入幅值为A：

~~~text
alpha=A*cos(phi)
beta =A*sin(phi)
~~~

将它们用估计角theta做Park：

~~~text
q=-alpha*sin(theta)+beta*cos(theta)
 =A*sin(phi-theta)
~~~

按幅值A归一化：

~~~text
error=q/A=sin(phi-theta)
~~~

真实相位领先时error为正，控制器应提高估计频率，让估计角追上去。
这里使用第73篇的负号和相序；若换了Park定义，环路符号也必须相应核对。

代码先计算hypot(alpha,beta)，再把alpha、beta各自除以幅值，
随后调用公共Park函数，得到无量纲的q轴误差。

## 4. PI输出的是频率修正

本篇在50Hz名义角频率附近调整：

~~~text
I_candidate=I_old+Ki*error*dt
omega_raw=omega_nominal+Kp*error+I_candidate
~~~

注意I已经包含Ki，单位为rad/s。
不能在使用I时再乘一次Ki，也不能把Hz直接与omega相加。

换算关系：

~~~text
omega=2*pi*f
f=omega/(2*pi)
~~~

比例项让相位误差迅速影响估计速度；
积分项则能保留持续频率偏差所需的修正。
例如输入长期为55Hz时，稳态积分需要提供约2*pi*5 rad/s的修正。

## 5. 从小误差模型选择参数

相位误差很小时：

~~~text
sin(phi-theta)≈phi-theta
~~~

忽略限幅、采样和噪声，连续小信号环路的特征式为：

~~~text
s²+Kp*s+Ki
~~~

和标准二阶形式比较：

~~~text
s²+2*zeta*wn*s+wn²
Kp=2*zeta*wn
Ki=wn²
~~~

本例采用zeta=1/sqrt(2)、wn=2*pi*10：

~~~text
Kp≈88.857658763 1/s
Ki≈3947.841760436 1/s²
dt=0.0005 s，即2000Hz采样
~~~

10Hz是这里选择的小信号自然频率参数，不直接等于整个闭环的−3dB带宽。
增大参数会改变跟踪速度和噪声敏感性，也需要重新检查离散稳定性。

初始化中的采样范围检查并没有检查所有PI增益的稳定性。
本篇只验证给定参数；不能把任意大Kp、Ki都视为可用。

## 6. 手算第一次调用

初始估计theta=0，输入alpha=cos(0.1)、beta=sin(0.1)，幅值为1。
真实相位领先0.1rad，因此：

~~~text
error=sin(0.1)≈0.099833417
I_candidate=Ki*error*0.0005
omega_raw=2*pi*50+Kp*error+I_candidate
theta_next=omega_raw*0.0005

I_candidate≈0.197063266 rad/s
omega_raw≈323.227292294 rad/s
theta_next≈0.161613646 rad
~~~

omega_raw比名义角频率高，说明控制方向正确。
check_boundaries将这组手算公式与实际更新结果逐项比较，
不只检查最后有没有达到55Hz。

## 7. 频率限幅与抗积分饱和

本例允许的估计频率为40～70Hz。
PI先计算候选积分与未限幅频率，然后判断：

~~~text
超过上限，并且本次积分增量>0：拒绝本次积分
低于下限，并且本次积分增量<0：拒绝本次积分
其余情况：接受本次积分
~~~

拒绝积分后，用旧积分重新计算频率，再限制到允许范围。
这能避免饱和期间继续朝错误方向积累积分。

程序专门构造q=+1和q=-1的输入，检查上、下限以及退出饱和。
该测试中的输入跟随估计角度构造，只用于检查分支逻辑，不是实际电网波形。

## 8. 相位更新到底是哪一拍

调用前，p.theta代表当前采样时刻的估计theta[k]。
用当前输入计算omega[k]，再执行：

~~~text
theta[k+1]=wrap(theta[k]+omega[k]*dt)
~~~

调用后，p.theta已经是下一拍的估计。
仿真先保存phi[k]-theta[k]的误差，再调用pll_step，最后推进真实相位。

如果先调用函数，再拿它与尚未推进的真实phi[k]比较，会凭空多出一拍相位差。
同样，外部代码不能拿更新后的theta再积分一次。

wrap将相位限制到[0,2*pi)。
它只改变表示范围，不改变方向；
比较两个相位时使用atan2(sin(delta),cos(delta))得到最短有符号差值。

## 9. 信号太小时怎么办

幅值低于minimum_amplitude=0.05时，不能可靠归一化鉴相。
本篇选择：

- 不更新积分。
- 保留最近估计频率。
- 继续按该频率推进相位。
- detector设为0，表示这次没有有效鉴相，不表示实际误差为0。

这是一种保持运行策略。
如果信号消失期间真实频率变化，估计相位会漂移。
本篇丢失测试故意保持真实频率55Hz不变，所以不能据此声称能跟踪丢失期间的频率变化。

## 10. 返回值不是锁定标志

| pll_step返回值 | 意义 |
| --- | --- |
| 1 | 幅值足够，完成了一次鉴相和更新 |
| 0 | 幅值不足，按最近频率继续走相位 |
| -1 | 输入或计算无效，整个结构保持不变 |

返回1不表示相位已经收敛。
真正的锁定判断通常需要连续多个样本满足误差、频率变化等条件，本篇没有实现。

调用者还应区分“有效的零幅值采样”和NaN等非法数据。
非法数据不会推进相位；是否停机、复位或按外部时间补偿，要由实际系统制定策略。

## 11. 怎样使用结构体和函数

PllConfig保存dt、PI参数、名义/上下限角频率和幅值门限。
Pll保存配置副本、相位、积分和最近频率。

~~~c
Pll pll = {0};
PllConfig cfg = example_config();

if (!pll_init(&pll, cfg, 0.0)) {
    /* 配置失败，不能开始运行。 */
}

/* 在配置成功之后，每隔cfg.dt秒执行一次： */
int status = pll_step(&pll, alpha_sample, beta_sample);
if (status < 0) {
    /* 本次无效，交给故障处理逻辑。 */
}
else {
    /* pll.theta属于下一拍，pll.omega用于刚完成的相位推进。 */
}
~~~

不要每拍重新初始化，否则积分和相位记忆都会丢失。
每个独立信号需要独立Pll实例。
不得由外部随意改写ready或内部状态。

## 12. 仿真事件与验证窗口

初始真实相位为0.7rad，估计为0。
随后安排：

| 时间 | 变化 |
| --- | --- |
| 0.5秒 | 真实相位增加0.4rad |
| 1.0秒 | 真实频率50→55Hz |
| 1.5秒 | 输入幅值2→0.4 |
| 2.0～2.1秒 | 三相输入消失 |
| 2.1秒 | 输入恢复，真实频率仍为55Hz |

五个误差统计窗口分别为：

~~~text
窗口0：[0.4,0.5)秒
窗口1：[0.9,1.0)秒
窗口2：[1.4,1.5)秒
窗口3：[1.9,2.0)秒
窗口4：[2.3,2.5)秒
~~~

每个窗口都检查最大绝对相位误差小于0.003rad，
最大频率误差小于0.02Hz。
它们是变化后留出恢复时间的窗口，不是全程最大瞬态误差或严格锁定时间。

最终估计为55.000000000Hz，保持运行共200拍。
前几个窗口的实际误差约为1e-8rad和1e-7Hz量级；
后面部分窗口在双精度下相位误差打印为0。

这些极小数值来自同一时钟下的无噪声、平衡、理想波形实验。
它们不代表真实硬件具备这样的精度。

## 13. 实际场景的限制

本例没有谐波、负序、直流偏置、采样抖动或ADC噪声。
不平衡三相经过基本SRF-PLL可能产生周期误差，需要更进一步的分量分离设计。
估计频率也没有额外低通平滑。

鉴相器输出是sin误差，具有周期性。
例如相差pi时q也可能为0，因此q接近0本身不足以证明正确锁定。
本篇没有证明任意初相、任意频偏的全局捕获，也未实现独立失锁检测。
