# 42 变化率限制

配套代码：[变化率限制.c](变化率限制.c)。本例采用标准 C99，无第三方依赖。

## 1. 解决目标值突然跳变

上层把目标速度从0改到1 m/s，不一定希望电机立即追这个突变。
变化率限制器把目标逐步推进，每次只允许改变一定量。

它限制输出，不拒绝目标。只要持续调用，输出最终会走到目标。
这与第38篇拒绝异常测量不同。

## 2. 单位最重要

| 参数 | 意义 | 以速度命令为例 |
| --- | --- | --- |
| value | 上次输出，成功后写入新输出 | m/s |
| target | 当前目标 | m/s |
| rise | 每秒最大上升量 | m/s² |
| fall | 每秒最大下降量，填非负大小 | m/s² |
| dt | 两次调用间隔 | s |

如果value表示角度，rise和fall就是rad/s。
如果value表示PWM占空比，变化率就是“占空比/秒”。

## 3. 公式和代码

~~~text
delta = target - value
up = rise*dt
down = fall*dt
delta = clamp(delta, -down, up)
new_value = value + delta
~~~

先求目标差，再限制这一步允许的差，最后更新输出。
代码在更新前检查有限数，避免极端参数乘法溢出污染状态。

rise或fall为0，表示该方向暂时不允许变化。
fall是正数，不应传入负数。

## 4. 手算与不越过目标

初始0，目标1，rise=2，dt=0.1，则最多增加0.2，输出0.2。
再经过0.4秒，最多增加0.8，输出正好达到1。

若当前0.6，目标0.5，fall=4，dt=0.1：
允许下降0.4，但实际只需下降0.1，所以输出0.5，不会降到0.2。
这就是限制“差值”而非固定每次增减一个步长的好处。

## 5. 如何放进控制系统

常见顺序：原始目标 → 变化率限制 → PID参考值 → 执行器。
状态value应在启用时初始化为合理当前参考，不能每个周期清零。

限制目标速度变化只能限制参考加速度，不能保证真实加速度一定符合约束。
执行器饱和、负载和闭环性能仍会影响真实运动。

本算法没有限制加加速度，所以不是S曲线。
到达目标或突然换目标时，斜率仍可能跳变。

## 6. 验证与成本

检查不同dt、不对称上升下降、接近目标时不越过、dt非法和单方向冻结。
每次O(1)，仅保存上次输出。
