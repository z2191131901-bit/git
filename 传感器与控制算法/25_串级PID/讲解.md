# 串级 PID：位置外环与速度内环

对应代码：[串级PID.c](串级PID.c)。控制器核心复用 [PID核心.h](../公共代码/PID核心.h)。

## 1. 为什么要分成两个环

位置误差并不直接告诉电机该输出多大驱动力。可以先由位置环决定“现在应该跑多快”，再由速度环决定“为了达到这个速度，要施加多大驱动力”。

数据流是：

```text
目标位置 - 实际位置 -> 位置外环 -> 目标速度
目标速度 - 实际速度 -> 速度内环 -> 驱动力命令
驱动力命令 -> 被控对象 -> 新位置、新速度
```

外环输出是内环目标，不是把两个控制器输出相加。

## 2. 本例选用 P 外环、PI 内环

PID各项可以设为0。本例外环Kp=2、Ki=Kd=0，内环Kp=4、Ki=3、Kd=0。

外环不用积分，是为了先讲清级联关系，也避免演示中出现“内环饱和而外环仍不断积分”的问题。如果以后外环加I，需要额外考虑内环实际能力和饱和信息反馈。

## 3. 两个环的单位不同

| 信号 | 单位 |
| --- | --- |
| 目标/实际位置 | m |
| 外环输出、目标速度 | m/s |
| 实际速度 | m/s |
| 内环输出 | 按单位质量归一化的m/s² |

外环输出限幅[-1,1]m/s，相当于限制给内环的速度目标。内环输出限幅[-3,3]，相当于驱动能力限制。这两个“1”和“3”不是同一个单位，不能互换。

## 4. 执行顺序与周期

内环每0.01秒计算一次，即100Hz；外环每5次内环计算一次，即20Hz。sample%5==0用于判断外环更新时间，%是取余。

外环没有更新的4次循环中，velocity_reference保持上次值，不能重置为0。两个环使用不同的PidState，不能共享积分和历史。

调用外环时dt传5*0.01=0.05秒，调用内环时dt传0.01秒。即使当前外环只是P，也应传正确周期，为以后扩展保持清晰接口。

## 5. 手算启动时刻

目标位置1m、当前位置0：

```text
位置误差=1
外环未限幅输出=2*1=2m/s
限幅后目标速度=1m/s
```

初始实际速度0，内环误差1。P=4，候选I=3*1*0.01=0.03，总输出4.03超过3。条件积分拒绝这一步增加，输出限制为3。

随后速度开始上升，位置误差逐步变小，外环会降低速度目标，使小车接近目标时减速。

## 6. 仿真对象是什么

```text
v_dot = command - 0.5*v
p_dot = v
```

0.5*v模拟线性阻尼。代码在一个周期内把command视为常数，对这个模型精确离散：

```text
decay=exp(-0.5*dt)
v_new=decay*v_old+command/0.5*(1-decay)
p_new=p_old+v_old*(1-decay)/0.5
      +command/0.5*(dt-(1-decay)/0.5)
```

更新位置时使用旧速度，之后才写新速度。这个仿真没有电机电气动态、摩擦死区和编码器噪声。

## 7. 调参顺序

先让速度内环独立工作，确认跟踪稳定且执行器限制正确，再关闭位置外环的I/D、逐步调整外环P。

通常希望内环响应比外环快。提高采样率并不自动等于提高闭环带宽；延迟、对象惯性和参数都影响响应。示例的5倍周期只是教学选择，不是通用规范。

## 8. 验证和限制

仿真目标1m，最终位置约1、速度约0，峰值位置约1.02973m。检查同时约束速度目标与驱动命令范围，并限制明显过大的超调。

这只说明本模型和参数下通过检查，不代表可直接移植到任意小车。加入外环积分、内环复杂执行器或不同采样周期时，应重新分析。
