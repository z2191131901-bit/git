# 41 死区处理

配套代码：[死区处理.c](死区处理.c)。本例采用标准 C99，无第三方依赖。

## 1. 用途与本例选择

摇杆松手后可能仍输出0.02或-0.03，电机因此缓慢运动。
设置零点附近的死区，让小偏差输出为零。

一种简单做法是死区外原样输出，但在边界会从0突然跳到死区宽度。
本例采用连续缩放：死区外重新映射，边界处仍从0开始。

## 2. 输入约定

input 已归一化到[-1,1]，width 是单侧死区宽度，范围[0,1)。
两者无单位。若ADC原始范围是0~4095，应先做零点校准和正负方向归一化。

output 是写出结果的指针。
本例对超出[-1,1]的输入返回失败，不偷偷裁剪；可在调用前使用第43篇限幅。

## 3. 公式

设 a=abs(input)，d=width：

~~~text
a <= d：y=0
a > d：y=sign(input)*(a-d)/(1-d)
~~~

减去d使边界对应0，再除以剩余有效区间1-d，使满量程仍对应1。
copysign负责恢复输入正负号，因此正负两侧对称。

先检查参数，成功才写output；失败返回0，原输出保持不变。

## 4. 手算

width=0.1，input=0.55：

~~~text
(0.55-0.1)/(1-0.1) = 0.45/0.9 = 0.5
~~~

输入-0.55得到-0.5；输入±0.1得到0；输入±1仍得到±1。
width=0时公式退化为原样输出。

## 5. 和电机死区补偿的区别

本篇是把小输入压成零。
电机死区补偿通常是为了克服静摩擦，在非零命令上补偿一定驱动力，方向恰好不同。
不要因为都叫“死区”，就把本函数当成电机静摩擦补偿。

把位置误差设死区也会允许一定稳态误差。
对精密位置控制是否合适，要结合实际目标。

## 6. 参数与检查

用静止摇杆的采样分布确定width，先校准中心，再留适当余量。
width太大，会让有效操纵范围变窄，死区外增益1/(1-width)增大。

main验证正负对称、边界、满量程和非法参数。
每次 O(1)，无内部状态。
