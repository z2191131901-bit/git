这份资料现在有76个可运行示例。编号是整理顺序，不是新手必须从头到尾学习的课程顺序。
第一次先读下面三篇，每次读一篇、手算一组数据、运行一次程序。

| 阅读顺序 | 打开哪篇 | 第一遍达到什么程度即可 |
| --- | --- | --- |
| 1 | [滑动平均入门](02_滑动平均滤波/讲解.md) | 能解释第5个读数来了后为什么丢掉第1个 |
| 2 | [PID入门](23_PID/讲解.md) | 能用目标、测量、Kp、Ki和dt算出一次PI输出 |

## 每一篇怎么读

先读要解决的问题和输入输出，再拿纸手算。
然后打开配套C代码，只看讲解指定的函数。
运行示例，把输出和手算对照；有余力时再做修改实验。
首次出现的新术语先看它在本例中的作用，不必立即掌握全部推导。

代码里的main是电脑演示入口，会提供模拟数据、调用算法并检查结果。
算法函数只做计算，真正传感器读取、驱动输出通常需要另外编写硬件接口。
不要把电脑模型运行成功理解为已经接好真实设备。

## 先认识几个反复出现的词

| 词 | 在这些示例中的意思 |
| --- | --- |
| 输入 | 交给算法的新数据或目标 |
| 输出 | 算法计算出的结果 |
| 状态 | 算法要记住、供下一次使用的数据 |
| 初始化 | 启动时给数据设定初始值 |
| 采样 | 获取一次测量 |
| dt | 两次更新的时间间隔，单位秒 |
| 反馈 | 把实际结果送回来比较 |
| 限幅 | 把命令限制到允许的上下界 |
| 仿真 | 用电脑模型代替真实对象，观察算法行为 |
| 验证 | 用已知答案或要求检查程序结果 |

代码里的单位不是装饰。10ms是0.01s；度、rad、rpm、rad/s不能混用。
不确定某个变量时，先查这篇的输入输出表，而不是根据名字猜。

## C代码先会读哪些写法

~~~c
double value = 0;       /* 保存一个小数。 */
State state = {0};     /* 创建状态，成员置零；State是相应结构体名称的示意。 */
function(&state, value, &result); /* 交出状态和结果的地址。 */
~~~

这是语法示意，不是可以直接复制运行的完整程序。
&取地址；函数里的*沿地址读写；->访问指针指向的结构体成员。
for用于重复执行。return通常把结果或成功标志交回调用处。
assert用于演示中的检查，条件不满足就终止。

暂时不熟悉指针也可以先读数字例子，知道地址是为了让函数更新外部变量。
不要把状态放在每次循环里重新初始化，否则历史会丢失。

## 在电脑上运行

在仓库根目录打开PowerShell，每次选择一篇：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 滑动平均滤波.c
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 PID.c
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 FOC电流与速度控制.c
~~~

需要gcc编译器能从命令行找到。若脚本提示找不到gcc，先配置编译环境。
脚本编译并自动运行，生成文件放在临时目录，原始中文文件名保留。
每个示例单独编译，不要把全部.c一起链接；验证时保持assert启用。

FOC原来的技术内容保留在[进阶原理与模型验证](76_FOC电流与速度控制/进阶原理与模型验证.md)。
需要看全部主题时，回到[算法目录](README.md)。
