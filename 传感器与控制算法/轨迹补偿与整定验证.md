环境：Windows、MinGW-w64 GCC 8.1.0；C99、-Wall -Wextra -Werror -pedantic、-lm。
全部62个示例编译运行通过；继电整定补充幅值稳定性和最小步长检查后又单独复验通过。

## 执行方式

仓库根目录：

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1
~~~

可执行文件和ASCII路径兼容副本写入系统临时目录，不提交生成文件。
断言保持启用，未定义NDEBUG。

## 检查覆盖

| 示例 | 独立检查 |
| --- | --- |
| 三次/五次轨迹 | 单位距离的解析中点速度与端点加速度、非零起终点速度/加速度、反向轨迹、非法时长、区间外查询 |
| S曲线 | 完整七段原始积分终点、速度/加速度约束、单调性、长/短距离、反向、低速度上限、退化边界、零距离 |
| 摩擦补偿 | 死区边界、逆映射正反扫描、静摩擦不启动、正负方向启动、零命令、相同PI下的误差积分 |
| 继电整定 | 10周期采集、周期/幅值稳定判据、与解析Ku=8及Tu=2π/√3比较、无效参数、生成PID后的独立闭环验证 |
| LQI | Riccati收敛、Bellman残差、积分方向、LQR稳态误差解析式、LQI扰动抵消、非法R保持原设计 |

S曲线终点检查直接积分七段，而不是只检查sample强制返回的goal，避免掩盖距离公式错误。
继电整定的Ku、Tu是描述函数近似，允许与解析临界量存在差异。
摩擦对比包含前馈和死区逆映射两项改变，没有单独归因到其中某一项。

## 验证边界

仅确定性数学与模型仿真，未进行实物验证。
多项式不会自动满足运动上限；S曲线只支持静止到静止；
摩擦模型固定且简化；继电整定仅在指定模型中主动激励，不是现场自动整定器；
LQI为无约束状态反馈，不含状态观测器或抗积分饱和。
轨迹生成检查并不等于真实闭环跟踪性能验证。
