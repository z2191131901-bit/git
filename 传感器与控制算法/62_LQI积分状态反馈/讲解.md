# 62 LQI积分状态反馈

配套代码：[LQI.c](LQI.c)。使用标准C99、中文注释和独立模型验证。

## 1. 从已有LQR继续往前走

第27篇用位置和速度反馈控制双积分对象。
没有扰动时可以回到目标，但未知恒定外力存在时，
控制器可能需要保留一点位置误差，才能产生抵消外力的控制量。

LQI把跟踪误差的积分也当成一个状态，然后对增广系统设计LQR。
它不是手工在LQR后面随意加一个Ki，而是把积分作用一起纳入状态反馈设计。

## 2. 原对象与单位

原连续模型：

~~~text
p'=v
v'=u+d
~~~

p单位m，v单位m/s，u和扰动d单位m/s²。
采样周期dt=0.05秒，区间内加速度保持不变：

~~~text
p_next=p+dt*v+dt²*(u+d)/2
v_next=v+dt*(u+d)
~~~

设计时使用名义模型d=0，仿真再加入未知扰动。

## 3. 积分状态如何定义

参考r保持常量，定义：

~~~text
e=p-r
z_next=z+dt*(r-p)=z-dt*e
~~~

注意位置误差状态用p-r，积分用r-p，两者符号相反。
这是明确选择，不是冲突；增广矩阵和控制律必须一起遵守。

z单位m·s。
三状态向量为x=[e,v,z]^T。

## 4. 增广矩阵

~~~text
A = [ 1    dt    0
      0     1    0
     -dt    0    1 ]

B = [dt²/2, dt, 0]^T
~~~

最后一行是积分更新，B最后一个元素为0，
因为本例采用旧位置误差的前向Euler积分，当前u不直接进入当拍z_next。

如果改用新位置或梯形法积分，就需要改变增广模型。
不能设计用一种积分式、运行时又写另一种。

## 5. 二次代价与反馈

~~~text
J=sum(x^T*Q*x + u^T*R*u)
Q=diag(10,1,5)
R=0.1
u=-K*x
~~~

Q的三个权重分别惩罚位置误差、速度和积分状态。
由于状态量纲不同，权重数值不能简单比较大小来判断“哪个更重要”。
R增加通常意味着更重视控制代价，但最终效果仍需结合对象验证。

这是无约束名义模型的无限时域二次型设计。
存在未知恒定扰动时，不把该仿真响应宣称为包含扰动模型后的最优解。

## 6. Riccati迭代逐步解释

初始P=Q，重复：

~~~text
S=R+B^T*P*B
K=S^(-1)*B^T*P*A
P_next=Q+A^T*P*A-A^T*P*B*S^(-1)*B^T*P*A
~~~

本例只有一个输入，所以S是标量，不需要通用矩阵求逆。
先算pb=P*B，再算bpa=B^T*P*A。
减去bpa[i]*bpa[j]/S后得到P_next各元素。

最多迭代20000次，以相对变化阈值检查收敛。
未收敛返回失败，不把最后一轮参数当成设计成功。
收敛后使用最终P重新计算K，避免增益滞后一轮。

## 7. 同一个设计函数怎样得到基线LQR

n=2时只使用A左上角、B前两项和Q前两项，就是已有双积分LQR模型。
n=3时加入误差积分，得到LQI。
这样基线与扩展使用同样的位置/速度权重和输入代价，仅多出积分状态与其权重。

本次LQI结果：

~~~text
K=[12.031957, 5.552237, -6.070621]
收敛迭代次数=362
~~~

积分增益为负并不表示正反馈。
控制律前面还有负号，且z定义为累积r-p：
低于目标时z增大，-Kz*z提供正加速度，方向正确。

## 8. 运行时顺序

先用当前p、v、z计算u。
再用旧位置更新z。
最后传播对象p和v。

参考r=1，初始p=v=z=0。
第5秒起加入恒定扰动d=0.3，运行总时间80秒。
仿真假定位置和速度都准确可用，没有状态观测器或测量噪声。

若硬件只能测位置，需要测速或状态观测器，不能把速度状态随便设为0。

## 9. 为什么LQR会有稳态位置差

LQR稳定后v=0，要抵消d必须u=-d。
而控制律为u=-Kp*(p-r)，所以：

~~~text
p-r=d/Kp
~~~

本例Kp约8.721547，故偏差约0.034398 m。
main用这个解析值检查基线，不只依赖“曲线看起来有误差”。

LQI中z可以保留非零值产生恒定补偿，不再需要位置误差提供全部输出。
实际检查最终位置误差小于10^-8，最终u=-0.3。
这是精确模型下的数值结果，不是实物精度承诺。

## 10. Bellman恒等式检查什么

任选状态x=[0.4,-0.2,0.3]，令u=-Kx，x_next=A*x+B*u。
应满足：

~~~text
x^T*P*x - x_next^T*P*x_next
= x^T*Q*x + R*u²
~~~

main检查残差接近0，帮助核对Riccati矩阵乘法、反馈符号以及积分方向。
另外验证非法R返回失败并保持既有设计结果。

## 11. 执行器饱和与目标变化

本例没有输出限幅，因此不包含积分抗饱和。
真实执行器达到限幅后，z可能继续累积，需要额外的抗饱和/参考管理设计。
简单限幅后仍可运行，但不能再声称保持无约束LQI的最优性。

参考在本例中保持常量。
连续变化的参考、非零目标速度、运动轨迹前馈要扩展误差模型，不是只把r每拍改掉就完成完整跟踪设计。

参考：[MathWorks LQI定义与积分状态反馈](https://www.mathworks.com/help/control/ref/ss.lqi.html)。
代码从离散增广模型和Riccati公式独立实现。
