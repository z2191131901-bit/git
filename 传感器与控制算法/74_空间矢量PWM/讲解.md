# 74 空间矢量PWM：把电压矢量换成三相占空比

[配套验证代码](空间矢量PWM.c) · [公共算法实现](../公共代码/空间矢量PWM.h) · [坐标变换基础](../73_电机坐标变换/讲解.md) · [本批验证记录](../抑振与电机控制基础验证.md)

## 1. 这篇位于控制链的哪里

电流控制器可以给出目标d、q轴电压。
经过逆Park，得到静止坐标中的alpha、beta目标电压。
PWM调制器的工作，是将这个电压请求转换为三个桥臂的占空比。

本篇从alpha、beta输入开始，输出duty_a、duty_b、duty_c。
没有实现完整FOC、电流控制器或真实开关波形。

## 2. 输入输出的物理含义

| 变量 | 含义 | 单位 |
| --- | --- | --- |
| alpha、beta | 目标相电压空间矢量的两个分量 | V |
| bus | 直流母线正负端之间的电压Vdc | V |
| duty_a/b/c | 对应上桥臂的导通占空比 | 0～1 |
| scale | 对原请求采用的共同缩放比例 | 无量纲 |
| limited | 请求是否被本例电压圆截断 | 0或1 |

占空比0.875表示一个开关周期内上桥臂导通时间占87.5%。
它不直接等于该相对负载中性点的电压除以Vdc。

本篇假设两电平三相逆变器，以及浮动中性点的三线制负载。
平均桥臂电压、相对负载中性点的相电压、相间线电压需要分清。

## 3. 为什么叫空间矢量

三个上桥臂各有开或关两种状态，一共有八种组合。
其中000和111不产生相间电压，是零矢量；
其余六种是有效矢量，在alpha/beta平面围成六边形。

一个开关周期内分配各状态的作用时间，可以合成期望的平均电压。
实际可合成区域是六边形。

本篇采用最大最小值公共偏置法。
在本篇线性范围内，它给出与对称SVPWM相应的三相平均占空比，
不必显式编写六段扇区分支。
具体的对称开关序列需要由采用同步载波的PWM硬件落实。

## 4. 第一步：电压请求的方向保持限幅

先计算矢量长度：

~~~text
magnitude=sqrt(alpha²+beta²)
~~~

代码用hypot计算，避免简单平方引入不必要的溢出。

为保证任意角度的旋转矢量都能处在线性范围，本例选六边形内切圆：

~~~text
maximum_voltage=Vdc/sqrt(3)
~~~

如果超出：

~~~text
scale=maximum_voltage/magnitude
alpha_applied=scale*alpha
beta_applied=scale*beta
~~~

两个分量乘同一个比例，所以方向不变。
单独截断alpha或beta则会改变方向。

这个圆是保守选择：六边形某些方向上还能容纳更大的静态矢量。
本例不利用那部分区域，也不实现过调制或六步运行。

12V母线时：

~~~text
maximum_voltage=12/sqrt(3)=6.928203230 V
~~~

这是本篇幅值不变坐标下的电压矢量峰值约束，不是线电压有效值。

## 5. 第二步：恢复三相目标电压

使用零序为0的逆Clarke：

~~~text
va=alpha
vb=-alpha/2+sqrt(3)*beta/2
vc=-alpha/2-sqrt(3)*beta/2
~~~

这三个目标值的和为0。
算法复用公共头文件，确保与第73篇的幅值和方向定义一致。

## 6. 第三步：为什么加同一个偏置

计算：

~~~text
highest=max(va,vb,vc)
lowest=min(va,vb,vc)
common=-(highest+lowest)/2
~~~

给三路同时加common：

~~~text
va_new=va+common
vb_new=vb+common
vc_new=vc+common
~~~

两相之差保持不变：

~~~text
va_new-vb_new=va-vb
~~~

但最大值和最小值会变得关于0对称，使三路更容易放进±Vdc/2范围。
这里是在调制器中注入公共模式电压，不能解释成给电机增加了相间电压。

对内切圆内的矢量，任意两个相电压之差的最大绝对值不超过sqrt(3)*magnitude，
因此最大相与最小相的差不超过Vdc。
把它们居中以后，两端就都不超过±Vdc/2。

## 7. 第四步：电压换成占空比

~~~text
duty_a=0.5+(va+common)/Vdc
duty_b=0.5+(vb+common)/Vdc
duty_c=0.5+(vc+common)/Vdc
~~~

0.5是母线中点对应的50%占空比。
最后的duty_roundoff_clamp只处理0、1边界的微小舍入误差；
真正的请求削减早已由电压矢量限幅完成。

如果占空比超出范围超过1e-12，函数返回失败，而不是隐藏异常继续截断。

## 8. 手算：12V母线，alpha=6V，beta=0

~~~text
三相目标：(6,-3,-3) V
highest=6，lowest=-3
common=-(6-3)/2=-1.5 V

偏置后：(4.5,-4.5,-4.5) V

duty_a=0.5+4.5/12=0.875
duty_b=0.5-4.5/12=0.125
duty_c=0.125
~~~

检查a、b之间的平均线电压：

~~~text
Vab=Vdc*(duty_a-duty_b)
   =12*(0.875-0.125)
   =9 V
~~~

这与原请求va-vb=6-(-3)=9V一致。

## 9. 测试不是只看占空比有没有越界

程序扫描360个角度，包含全部六个扇区。
每个角度测试内切圆半径的0、0.8、1、1.8倍，共1,440组请求。

然后由占空比恢复桥臂对母线中点的平均电压：

~~~text
pole_a=Vdc*(duty_a-0.5)
pole_b=Vdc*(duty_b-0.5)
pole_c=Vdc*(duty_c-0.5)
~~~

重新做Clarke，核对实际alpha、beta是否等于期望的限幅结果。
同时核对线电压，而不仅检查范围。

本机最大矢量重建误差约3.2e-15V，属于双精度舍入量级。
这不包括真实ADC、定时器、功率器件和母线波动的误差。

另有两个边界手算：

- 零矢量：三个占空比都是0.5，相间电压为0。
- 内切圆30度切点：三个占空比为1、0.5、0。

## 10. 调用与失败处理

~~~c
PwmResult command;
if (svpwm(alpha_voltage, beta_voltage, bus_voltage, &command)) {
    /* command.duty_a/b/c交给硬件PWM层。 */
    /* command.limited和scale可供上层控制器判断电压余量。 */
}
else {
    /* 输入非法，不能把旧输出当作本拍的新命令。 */
}
~~~

成功返回1，失败返回0，失败时输出结构不变。
bus小于1e-9V、非有限输入或计算溢出会被拒绝。
1e-9只是示例数值保护，真实欠压阈值需要由硬件要求决定。

当电压请求被削减时，上层PI应考虑积分抗饱和。
本函数仅报告削减结果，没有代替电流控制器管理积分状态。

## 11. 移植到硬件还缺什么

需要根据定时器模式完成占空比到比较寄存器的换算，并处理：

- 上下桥臂互补输出、死区和关断逻辑。
- 最小导通时间、采样窗口及占空比边界余量。
- 母线测量、PWM更新同步和ADC采样时刻。
- 器件压降、死区引起的电压误差及电流环延迟。

因此，数学上允许占空比0和1，不表示每块硬件都应该直接采用这些端点。
本篇只验证平均调制关系，未进行电机或逆变器实测。
