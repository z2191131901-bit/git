# 一维卡尔曼：预测与测量应该各信多少

对应代码：[一维卡尔曼滤波.c](一维卡尔曼滤波.c)。

## 1. 先理解它要解决的问题

用最简单的随机游走模型理解卡尔曼滤波。状态只有一个数，例如缓慢变化的温度或距离；它不是通用运动追踪器。

## 2. 输入、输出与约定

ScalarKalman.value 是估计值，variance 是估计误差方差 P。process_variance=Q 表示每一步模型增加的不确定性，measurement_variance=R 表示测量噪声方差。P/Q/R 的单位都是被测单位的平方。

## 3. 公式先看懂每个量

```text
预测值 x_minus = x
预测方差 P_minus = P + Q
增益 K = P_minus/(P_minus+R)
新估计 x = x_minus + K*(z-x_minus)
新方差 P = (1-K)^2*P_minus + K^2*R
```

## 4. 按执行顺序读代码

### 第 1 步：先给初始值和信心

初始化 {10,4} 表示估计为 10，误差方差为 4，即标准差为 2。方差越大，说明当前估计越不确定；不要把方差与标准差混为一谈。

### 第 2 步：预测阶段

随机游走模型没有已知运动量，所以 value 不变，但 variance 增加 Q。这并不是所有卡尔曼模型的预测公式，位置速度模型会有不同的状态转移。

### 第 3 步：测量更新

measurement-value 是创新，也就是测量与预测之间的差。K 决定只向测量靠近多少。预测更不确定时 K 较大；测量更不确定时 K 较小。

### 第 4 步：Joseph 方差表达

代码用两个非负平方项更新方差，在浮点数下比直接相减的表达更稳健。标量模型中它与 (1-K)*P_minus 在精确运算下等价。

### 第 5 步：缺测处理

valid=0 时只进行预测，measurement 可以是 NaN，因为它不被用于计算。R 仍按接口要求为正，防止传入未初始化参数。

## 5. 代入数字算一次

x=10，P=4，Q=0，测量 z=14，R=4。K=4/(4+4)=0.5，x_new=10+0.5×4=12。P_new=0.5²×4+0.5²×4=2。随后缺测一次，Q=1，估计仍为12，但方差增加到3。

## 6. 参数怎样选

Q 大表示允许状态更快变化，R 大表示测量噪声更强。静态采样可估计 R，但实际还需检查噪声模型。代码 Q 是每一步方差，采样周期变化时要按连续过程模型重新离散化，不能不加区分地保持同一数值。

## 7. 常见错误与适用边界

它不是消除所有异常的万能滤波器。跳点可能直接拉动估计；需要额外异常值处理。快速运动目标不符合随机游走假设时，应使用包含速度或加速度的模型。

## 8. 示例验证了什么

检查均等方差下的 12/2 手算结果、缺测时方差增长、R=0 拒绝且状态保持、连续测量收敛及方差非负。时间和额外存储 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。
