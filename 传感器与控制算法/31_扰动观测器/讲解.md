# DOB：把实测与无扰动预测的差当作线索

对应代码：[扰动观测器.c](扰动观测器.c)。

## 1. 为什么已有反馈还要估计扰动

P反馈可以减少偏差，但持续负载可能留下稳态误差。若能估计外扰，就可以提前加一个反方向补偿，让反馈主要处理剩余误差。

DOB是扰动观测器的统称。本篇是“已知一阶名义模型的逆计算＋低通”教学实现，不是任意对象的通用鲁棒DOB设计器。

## 2. 扰动放在哪里决定单位

本例模型：

```text
y_dot=-a*y+b*u+d
```

d是输出变化率端的扰动。例如y是速度，d的单位就是加速度。若资料把扰动写成输入端u+d_input，则它与这里相差b的比例，不要混用。

a>0、b>0，采用正作用稳定一阶对象。

## 3. 从连续模型变成一周期关系

输入和扰动在周期内近似不变时：

```text
A=exp(-a*dt)
B=b*(1-A)/a
D=(1-A)/a
y[k]=A*y[k-1]+B*u[k-1]+D*d[k-1]
```

因此可以反算：

```text
raw_disturbance=(y[k]-A*y[k-1]-B*u[k-1])/D
```

这相当于看实际系统比名义预测多走了多少，再除以扰动在一个周期内的作用系数。

## 4. 为什么再接一个低通

传感器噪声会进入两个相邻测量的差。dt很小时D约等于dt，除以一个很小的数会放大噪声。

代码采用：

```text
alpha=dt/(tau+dt)
d_hat_new=d_hat_old+alpha*(raw_disturbance-d_hat_old)
```

tau越小，响应通常越快，但更容易追随噪声。不能简单把带宽调到很大就认为补偿更好。

## 5. 对照字段与更新步骤

DobConfig保存A/B/D/alpha，模型和周期不变时只设计一次。DobState保存上一条测量和扰动估计。

第一条数据没有上一周期信息，先存measurement，扰动初值取0。后续才进行残差反算。

previous_applied_input必须是上一周期真正施加的输入。若执行器只能输出1，你却把未限幅的期望10传入，观测器会错误地把执行器饱和当成很大外扰。

代码用-expm1(-a*dt)计算1-exp(-a*dt)，改善很小dt下两个接近1的数相减造成的精度损失。

## 6. 反向补偿怎么加入

示例选择：

```text
u=(a*reference + kp*(reference-y)-d_hat)/b
```

最后做执行器限幅。本例a=2、b=1、kp=3、目标0.5。

a*reference提供名义稳态前馈，kp项做误差反馈，-d_hat补偿估计扰动。实际输出再存为previous_input，供下一周期观测器使用。

## 7. 手算首次扰动估计

dt=0.01、tau=0.05，alpha=1/6。原来y=0、u=0，现在出现恒定扰动0.4。下一次测量为D*0.4。

反算raw_disturbance正好0.4，但低通后的第一次估计只有0.4/6≈0.066667，随后逐步靠近0.4。这也解释了补偿不会在扰动刚出现时瞬间完美。

## 8. 有补偿与无补偿的比较

外扰0.4持续存在时，无DOB稳态：

```text
0=-2*y + [2*0.5+3*(0.5-y)] + 0.4
得到y=0.58
```

估计收敛到0.4后，补偿抵消该项，输出回到0.5。示例两种仿真使用同一真实模型、同一扰动和同一反馈参数。

## 9. 局限与验证

本例DOB名义模型等于真实一阶模型；模型错误也会进入扰动估计，不能再把估计值解释为纯外部负载。高频噪声、延迟、非最小相位对象和不匹配动力学需要更完整分析。

检查了稳态0.58/0.50、扰动估计0.4、首次低通结果和NaN输入保持旧状态。单步O(1)，状态O(1)，未接真实硬件。
