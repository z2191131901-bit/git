## 一次编译并验证所有示例

Windows PowerShell 中，从当前目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./验证全部示例.ps1
```

需要 gcc 在 PATH 中。ExecutionPolicy Bypass 仅作用于本次启动的 PowerShell 进程，不修改系统的永久执行策略。脚本以 C99、警告视为错误、不开启 NDEBUG 的方式编译每个源文件，然后执行其 main 中的检查。产物写入系统临时目录，避免污染仓库。失败会停止并返回非零退出码。

本次命名调整已在 Windows 验证。每篇提供统一 PowerShell 编译入口；Linux/macOS 尚未验证。旧版 MinGW 的中文头文件兼容由脚本在临时副本中处理。

每个 .c 都有独立 main，不应把所有 .c 一起链接成同一个程序。移植到 MCU 时提取结构体和算法函数，用真实采样替换 main 的模拟数据；函数当前使用 static，仅在各自源文件内可见。
