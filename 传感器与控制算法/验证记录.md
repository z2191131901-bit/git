# 验证记录

## 环境与命令

本次使用 Windows、MinGW-w64 GCC 8.1.0，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./验证全部示例.ps1
```

脚本对每个 .c 单独使用 -std=c99 -Wall -Wextra -Werror -pedantic 编译，并链接数学库。全部22个示例编译成功，运行退出码为0。未定义 NDEBUG，因此 assert 检查有效。编译产物位于临时目录，不上传仓库。

## 本批新增检查

| 示例 | 关键验证 |
| --- | --- |
| 四元数基础 | 归一化、逆旋转、旋转顺序不可交换、无效四元数 |
| 增量四元数 | 恒定90°旋转解析解、一步与100步一致、静止、非法dt |
| 欧拉角 | 混合姿态恢复、±90°奇异姿态重建等价 |
| Mahony | 零角速度下倾角收敛、可选磁航向收敛、积分项估计残余零偏 |
| Madgwick六轴 | 倾角收敛、零梯度安全处理、无参考时陀螺仪积分 |
| 一维卡尔曼 | 手算增益结果、缺测预测、非法R、恒定测量收敛 |
| 静止检测 | 填满窗口、转动退出、恢复、自由落体、横向振动 |
| 六面校准 | 已知偏移和比例恢复、退化正反读数拒绝 |
| 磁力计校准 | 已知轴对齐椭球恢复、未用于拟合的方向、退化采样 |
| 倾斜补偿航向 | 有横滚/俯仰/磁倾角的已知航向恢复、无水平磁场拒绝 |
| 重力去除 | 倾斜静止、已知世界加速度、自由落体 |
| Butterworth | 截止频率幅值、阻带、直流、NaN与非法设计频率 |
| 陷波 | 目标频率抑制、非目标频率通过、直流、非法Q |
| 编码器 | 计数与周期法一致、倒车、超时、非法时间 |
| 差速里程计 | 直行、倒车、原地转弯、圆弧、非法轮距 |

原有7个示例也通过同一脚本验证。

这些是合成输入和已知结果检查。没有实物传感器、噪声数据集、实时性测试或 MCU 性能测量，不能据此声称已完成产品级验证。滤波参数和检测门限需要根据实际采样、安装和噪声重新设置。

测试不会把所有姿态误差归零作为通用保证。尤其六轴航向不可观、磁场动态干扰、轮胎打滑等物理限制，要结合各篇讲解理解。
