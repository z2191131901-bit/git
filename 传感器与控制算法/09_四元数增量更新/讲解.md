# 增量四元数：把一小段旋转接到旧姿态上

对应代码：[四元数增量更新.c](四元数增量更新.c)。

## 1. 先理解它要解决的问题

原始样稿通过导数做一阶积分。这篇直接用采样间隔内的旋转轴和转角构造增量，再与旧姿态相乘。具体函数 quat_step 在公共数学头文件中。

## 2. 输入、输出与约定

输入 q 为机体到世界的姿态，rate 为机体坐标系三轴角速度 rad/s，dt 为秒。成功后原 q 更新；失败返回 0，q 保持原值。

## 3. 公式先看懂每个量

```text
speed = sqrt(wx²+wy²+wz²)
theta = speed*dt
delta = [cos(theta/2), wx*sin(theta/2)/speed,
         wy*sin(theta/2)/speed, wz*sin(theta/2)/speed]
q_new = normalize(q_old * delta)
```

## 4. 按执行顺序读代码

### 第 1 步：复制旧姿态

previous=*q 是结构体复制，先验证并归一化副本。这样参数非法时可以返回，而不改动旧状态。

### 第 2 步：求角速度大小

vec_norm(rate) 得到合成角速度 speed。它不是三个角度的简单相加，而是向量长度。方向由 rate/speed 给出。

### 第 3 步：计算半角

half_angle=speed*dt/2，因为四元数使用旋转半角。只要 dt 的单位误传成毫秒，角度就会放大一千倍。

### 第 4 步：处理零角速度

直接计算 sin(half_angle)/speed 会在静止时产生 0/0。小角度时使用 dt/2*(1-half_angle²/6)，这是 sin(x)/x 的展开；零转速因此自然得到单位增量。

### 第 5 步：右乘并写回

quat_multiply(previous,delta) 对应机体系角速度约定。结果归一化通过后，才执行 *q=next。每轮必须继承上轮结果，不能每次重置单位四元数。

## 5. 代入数字算一次

绕 Z 轴以 π/2 rad/s 转 1 秒，theta=π/2，delta=[cos(π/4),0,0,sin(π/4)]。若旧姿态为单位四元数，新姿态就等于 delta。若分成 100 次、每次 0.01 秒，恒定角速度下应得到同一结果。

## 6. 参数怎样选

dt 应来自采样时间戳或可靠固定周期。增加采样率可以更好地描述采样之间变化的角速度，但不能凭空补回已经丢失的运动信息。

## 7. 常见错误与适用边界

它对单步内恒定角速度的旋转是精确表达，不代表任意运动积分都无误差。快速变轴、锥运动、传感器零偏和时间戳错误仍会影响结果。它没有加速度计或磁力计校正，仍会漂移。

## 8. 示例验证了什么

验证 90° 解析结果、一步与百步等价、零角速度保持姿态、负 dt 拒绝且状态不变。计算与额外存储都是 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。
