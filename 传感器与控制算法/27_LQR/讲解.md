# LQR：根据模型与代价，求一组状态反馈系数

对应代码：[LQR.c](LQR.c)。

## 1. 为什么学完PID还要看LQR

PID直接用误差及其历史构造控制量。LQR先明确状态怎样变化，再告诉算法“位置偏差、速度和控制用力各有多重要”，由此计算反馈系数。

这里的LQR是离散、线性、无约束、无限时域调节器。名称里的“最优”依赖指定模型和二次代价，不表示对真实系统的一切要求都最优。

## 2. 状态与模型

状态是两项：

```text
x = [position, velocity]^T
u = acceleration
```

单位分别为m、m/s、m/s²。假设一个采样周期内加速度恒定：

```text
position_next = position + dt*velocity + 0.5*dt²*u
velocity_next = velocity + dt*u
```

矩阵写法：

```text
x_next = A*x+B*u
A = [1  dt]    B = [0.5*dt²]
    [0   1]        [dt     ]
```

这是双积分模型，不含摩擦、时延和执行器动态。若用在实际对象上，应先判断这个模型是否合适。

## 3. Q与R是什么意思

我们希望累计代价小：

```text
J = Σ (x[k]^T*Q*x[k] + R*u[k]²)
Q = diag(q_position,q_velocity)
```

本例q_position=10、q_velocity=1、R=0.1。

位置偏差大要付代价，速度大也要付代价，用力大同样要付代价。它们的单位不同，权重负责表达相对偏好。LQR的Q/R是控制代价权重，不能与卡尔曼滤波里的过程/测量噪声方差混为一谈。

R需要严格为正。本专用实现还要求位置权重为正、速度权重非负。

## 4. 为什么最终变成u=-K*x

在这些条件下，最优剩余代价可以写成V(x)=x^T*P*x。将一步代价加上下一时刻V(x_next)，对u求极小值，就能得到：

```text
K = (R+B^T*P*B)^(-1)*B^T*P*A
u = -K*x
```

这里输入只有一个，R+B^T*P*B是一个标量，所以代码直接做除法，不需要通用矩阵求逆库。

K有两个数：第一个乘位置，第二个乘速度。前面的负号表示把偏离原点的状态往回拉。

## 5. P怎样求出来

代码从P=Q开始重复离散Riccati递推：

```text
P_next = Q+A^T*P*A
         -A^T*P*B*(R+B^T*P*B)^(-1)*B^T*P*A
```

直到P的变化足够小，或达到最大迭代次数。不是随便重复固定次数就宣布成功；若未收敛，函数返回失败，保留原输出。

迭代通常在初始化或模型改变后做，运行时只计算u=-K*x，不应每个高速采样周期都重新迭代求K。

## 6. 对照代码里的矩阵乘法

riccati_step先算pb=P*B。因为P理论上对称，B^T*P就是pb的转置。

denominator是R+B^T*P*B。对本模型：

```text
K[0] = pb[0]/denominator
K[1] = (pb[0]*dt+pb[1])/denominator
```

随后四层小循环计算A^T*P*A。row/col选择结果位置，i/j表示中间相乘求和的索引。矩阵固定2×2，不会随输入大小动态增长。

减去denominator*K[row]*K[col]，再加上Q，就得到P_next。两个非对角元素取平均以消除数值舍入带来的微小不对称。

(const double (*)[2])是“指向每行包含两个double数组的指针”的类型转换，仅为兼容旧C99编译器对二维数组const的处理，不是把数据换成新的矩阵。

## 7. 代入实际结果

本例dt=0.05秒，求得：

```text
K ≈ [8.721547, 5.004961]
```

如果位置为1m、速度为0：

```text
u = -8.721547*1 - 5.004961*0
  ≈ -8.721547 m/s²
```

如果正向速度也很大，第二项进一步提供制动；如果速度已经朝原点方向运动，速度反馈会相应调整用力。

这个数值也直接提醒你：无约束设计可能要求现实执行器做不到的加速度。事后限幅可以保护输入范围，但此时已不是原来的无约束最优控制，闭环性能需要重新验证。

## 8. 怎样判断这次结果可信

示例做三层检查：

1. A-BK的特征值模小于1，表明这个离散线性闭环渐近稳定。
2. 核对V(x)=x^TQx+Ru²+V(x_next)，即最优代价的一步一致性，残差足够小。
3. 从非零位置和速度开始仿真，最终收敛到原点。

实际算出的谱半径约0.872155，Riccati递推102次收敛。具体末位和次数可随数值环境略有差异。

## 9. 目标跟踪与状态来源

当前示例是回到原点。若要停到固定目标位置，可对position-reference使用相同反馈，并让目标速度为0；更复杂轨迹需要相应参考状态和前馈。

LQR需要位置和速度状态。速度不可直接测时，需要估计器；不能把噪声很大的差分值未经处理直接当成理想状态。这也为以后学习卡尔曼估计与LQG做铺垫。
