# 70 比例谐振 PR 控制：怎样专门跟踪正弦目标

配套代码：[比例谐振PR控制.c](比例谐振PR控制.c)  
验证汇总：[补偿谐振与死拍控制验证](../补偿谐振与死拍控制验证.md)

## 1. 先理解要解决的问题

前面的 PI/PID 很适合调节恒定目标，例如让速度保持在某个值。
但如果目标每秒来回变化 50 次，控制器还要同时跟上目标的幅值和相位。
仅有 P 控制时，增大增益可能改善跟踪，却也会扩大更宽频段的反馈作用。
PR 的思路是：保留比例支路，再增加一个主要在指定频率附近起作用的谐振支路。

本篇只处理一维归一化对象和一个正弦目标。
在交流电流、电压控制中也能遇到这种结构，但本例没有逆变器、PWM、采样延迟或电网模型。
先读懂差分方程和反馈关系，再考虑具体硬件的对象建模。

## 2. 理想 PR 与本篇准 PR

一种理想形式是：

```text
C_ideal(s) = Kp + 2*Ki*s / (s² + w0²)
```

它在 w0 处存在虚轴极点，形式上的谐振增益趋于无穷大。
在闭环稳定、目标频率准确等条件满足时，内模可以支持对该频率的零稳态误差。
这不代表任意对象接上理想 PR 都稳定，也不代表普通有限精度程序会自动得到零误差。

本篇实现有限带宽的准 PR：

```text
C(s) = Kp + R(s)
R(s) = 2*Kr*wc*s / (s² + 2*wc*s + w0²)
```

它增加了阻尼，谐振支路自己的极点在左半平面。
把 s=j*w0 代入，可得到 R(j*w0)=Kr，因此中心处总增益为 Kp+Kr。
本篇 Kr=30、Kp=2，所以中心处是 32，属于有限增益。
结果仍有稳态正弦跟踪误差，后面的仿真明确保留这个误差。

注意 Ki 和 Kr 的定义不能混用：
理想式中的 Ki 单位包含每秒，本篇 Kr 是“控制输出单位/误差单位”。
若保持本篇 Kr 不变而让 wc 趋于零，不能直接得到上面固定 Ki 的理想 PR。

## 3. 参数、单位和带宽

| 变量 | 含义 | 本例数值 |
|---|---|---|
| kp | 比例增益 | 2 |
| kr | 谐振支路中心增益 | 30，基线设为 0 |
| w0 | 中心角频率，rad/s | 2π×50 |
| wc | 阻尼带宽参数，rad/s | 2π×2 |
| dt | 固定采样周期，s | 0.0002 |
| tau | 被控对象时间常数，s | 0.02 |
| error | 目标减测量值 | 归一化量 |
| resonant | 谐振支路输出 | 归一化量 |
| output | 比例与谐振支路之和 | 归一化量 |

Hz 表示每秒多少个周期，rad/s 表示每秒多少弧度，两者相差 2π。
代码中 w0、wc 都使用 rad/s，不能把 50 直接当成 w0。

这里的 wc 不能直接称为“完整 -3 dB 带宽”。
只看连续谐振支路 R(s)，相对其峰值 Kr 的两个半功率角频率是：

```text
w_low  = sqrt(w0² + wc²) - wc
w_high = sqrt(w0² + wc²) + wc
w_high - w_low = 2*wc
```

所以完整 -3 dB 带宽是 2*wc rad/s，本例为 4 Hz。
端点约为 48.039984 Hz 和 52.039984 Hz，并非严格关于 50 Hz 算术对称。
这是谐振支路的带宽，不能直接当成整个控制器或整个闭环的带宽。
数字化之后还要经过频率映射，两个端点约为 48.041199 Hz 和 52.038559 Hz。

## 4. Tustin 离散化，一步一步看

为了在固定周期中计算，使用以下替换：

```text
q = z^-1                         表示延迟一个采样周期
s = k*(1-q)/(1+q)
k = w0/tan(w0*dt/2)
```

普通 Tustin 使用 k=2/dt。
本例使用中心频率预畸变：让目标数字频率 w0 对应的连续频率仍然是 w0。
它精确保留指定中心频率的位置，不能同时让全部频率都没有变形。

把替换式代入 R(s)，分子分母同时乘以 (1+q)²：

```text
分子 = 2*Kr*wc*k*(1-q²)

分母 = k²*(1-2q+q²)
     + 2*wc*k*(1-q²)
     + w0²*(1+2q+q²)
```

按 q 的次数整理，再除以常数项：

```text
d0 = k² + 2*wc*k + w0²

b0 = 2*Kr*wc*k / d0
a1 = 2*(w0²-k²) / d0
a2 = (k²-2*wc*k+w0²) / d0

R(z) = b0*(1-z^-2) / (1+a1*z^-1+a2*z^-2)
```

本例计算结果：

```text
k  = 9996.709915381307
b0 = 0.075159850393
a1 = -1.991052687550
a2 = 0.994989343307
```

不要把公式中的 a1 改成正数。
递推式里本来就有减号，“减去负数”在本组参数中会产生正贡献。

## 5. 对应到 C 代码的每一步

将上一节传递函数两侧交叉相乘，并把历史输出移到右侧：

```text
v[k] = b0*(e[k]-e[k-2]) - a1*v[k-1] - a2*v[k-2]
u[k] = kp*e[k] + v[k]
```

pr_update() 中的 error 就是 e[k]，resonant 就是 v[k]，command 就是 u[k]。

结构体保存四个历史量：

- e1：e[k-1]，上一次误差。
- e2：e[k-2]，上上次误差。
- v1：v[k-1]，上一次谐振输出。
- v2：v[k-2]，上上次谐振输出。

先用旧的 e2、v1、v2 计算新结果，再把 e1 移到 e2，把新误差存入 e1。
输出历史同样先后移动。
虽然公式没有直接用 e1，它仍负责把误差保存到下一拍的 e2。

实时更新不需要复数运算。
代码中的 complex、cexp 和 cabs 只用于测试频率响应，可与控制器运行部分分开移植。

## 6. 手算前三拍，检查历史量有没有写反

假设历史量都是零，输入一个单位脉冲：第 0 拍误差为 1，随后全为 0。
这只是对控制器本身的开环输入测试，不是完整对象闭环。

```text
第0拍：
v[0] = b0
u[0] = kp+b0 = 2.075159850393

第1拍：
v[1] = -a1*b0
u[1] = 0.149647222121

第2拍：
v[2] = -b0-a1*v[1]-a2*b0
     = (a1²-a2-1)*b0
u[2] = 0.148012403210
```

程序对这三个结果做 assert。
这能发现历史更新顺序、反馈符号或遗漏两拍误差等常见问题。
程序还检查直流输入最终只剩比例输出，说明本篇没有提供直流积分功能。

## 7. 仿真的对象和计算顺序

对象使用一阶模型：

```text
tau*y_dot + y = u

A = exp(-dt/tau)
B = 1-A
y[k+1] = A*y[k] + B*u[k]
```

假定每个采样间隔内 u 保持不变，上式是精确的零阶保持离散。
本例 A≈0.990049833749，B≈0.009950166251。

每次循环按以下顺序执行：

1. 生成当前目标 r[k]=sin(2π*f*k*dt)。
2. 用当前测量 y[k] 计算 e[k]=r[k]-y[k]。
3. 更新控制器得到 u[k]。
4. 记录当前误差和输出。
5. 更新对象到 y[k+1]。

误差记录在更新对象之前，避免把 r[k] 与 y[k+1] 错位比较。
模拟共 4 秒，统计最后 2 秒，给启动瞬态留出衰减时间。
50 Hz 和 55 Hz 在这段统计窗口中都包含整数个周期。

## 8. 公平比较和实际结果

P 基线与准 PR 使用同一对象、kp、采样周期、目标幅度、初值和统计窗口。
唯一变化是 kr 从 0 增加到 30。

| 目标频率 | 控制器 | 稳态误差 RMS | 全程控制输出绝对峰值 |
|---|---|---:|---:|
| 50 Hz | P | 0.651469914 | 1.905631 |
| 50 Hz | 准 PR | 0.134659630 | 7.276303 |
| 55 Hz | P | 0.660987097 | 1.940739 |
| 55 Hz | 中心仍为 50 Hz 的准 PR | 0.605883814 | 10.908793 |

50 Hz 处的误差明显降低，同时需要更大的控制输出。
目标变成 55 Hz 后，固定中心的准 PR 跟踪能力明显退化，控制峰值也更大。
这说明频偏不只是一个“增益变小”的问题，还会改变闭环的相位和放大特性。
本例 55 Hz 仍比相同 kp 的 P 略好，但不能推导出所有频偏下都更好。

若换一个更大 kp，P 也可能改善；本表只展示增加特定频率支路的效果。
它不声称准 PR 在全部调参方式下都优于其他控制器。

## 9. 为什么要再做一次频率响应检查

仅检查“PR 比 P 误差小”可能漏掉共同存在的时间错位或公式错误。
程序还在同一数字频率处独立计算：

```text
z = exp(j*w*dt)
P(z) = B/(z-A)
C(z) = kp + b0*(1-z^-2)/(1+a1*z^-1+a2*z^-2)

E/R = 1/(1+P(z)*C(z))
预测误差RMS = |E/R|/sqrt(2)
```

四种仿真的时域 RMS 都与该预测值相差小于 1e-8。
同时检查中心总增益为 kp+kr，直流和 Nyquist 处总增益为 kp。

离开中心后，比较连续和离散响应要使用：

```text
w_analog = k*tan(w_digital*dt/2)
```

直接拿两个相同数值的频率比较，会把 Tustin 固有的频率变形误认为代码错误。
这些测试验证当前参数和递推实现；它们不能代替任意新对象的闭环稳定性分析。

## 10. 配置、失败处理和调参顺序

控制器先用 QuasiPr controller={0} 创建，再调用 pr_configure()。
配置成功时历史量被清零，非法参数时原状态保持不变。
pr_update() 检查 NaN 和计算溢出；失败时输出参数和历史量都不更新。
调用者应检查返回值，不能忽略失败后直接执行旧控制量。

pr_configure() 还检查二阶支路分母的 Jury 条件。
这只能说明谐振支路自身在离散域稳定，不能证明接上对象后的整个闭环稳定。

可以按照这个顺序调参：

1. 确认采样周期和对象模型，先建立能稳定工作的 P 基线。
2. 把 w0 设为目标正弦角频率，分清 Hz 与 rad/s。
3. 从较小 kr 开始，观察目标频率处误差和控制输出峰值。
4. 根据允许的频偏调整 wc，并重新检查闭环响应。
5. 加入实际延迟、噪声、执行器约束后重新验证。

增大 kr 会提高中心增益，也可能增加控制需求、振荡或稳定性风险。
增大 wc 会拓宽谐振支路的作用范围，也会改变更多频率处的增益和相位。
运行中修改 w0 需要重新计算系数并考虑状态连续性，本例没有实现频率自适应。

## 11. 范围和容易误用的地方

本篇没有输出限幅，也没有抗谐振状态累积的处理。
assert(peak_output<12) 仅验证本组仿真没有超过选定检查值，它不是执行器限幅。
如果硬件最大输出只有 2，本篇的 PR 仿真结果就不能直接套用。

目标幅度为 1 不代表控制输出也会小于 1。
当对象有明显相位滞后时，追踪快速正弦可能需要幅度更大的输入。

没有加入直流积分、多谐波支路、锁相环、频率估计、负载扰动和量化噪声。
没有包含 ADC/PWM 时序和额外计算延迟，也没有进行实物验证。
不能仅把本例参数复制到逆变器或交流电机，就认为控制器已完成设计。

在仓库根目录的 PowerShell 中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\传感器与控制算法\验证全部示例.ps1 -示例 比例谐振PR控制.c
```

脚本用 C99、Wall、Wextra、Werror 和 pedantic 编译，链接数学库，并运行全部断言。
Bypass 只作用于这一次子进程，不修改系统执行策略。
本文件同时包含算法和断言式测试入口，请不要定义 NDEBUG 来运行验证。
正常结束会打印四行仿真对比及 PASS。
