# 增量式 PID：这次输出应比上次多多少

对应代码：[增量式PID.c](增量式PID.c)。建议先读位置式PID。

## 1. 与位置式有什么区别

位置式直接计算本次u；增量式先计算delta_u，再执行u_new=u_old+delta_u。两者在不饱和、参数固定、离散形式一致且初始条件匹配时，可以表达同一个控制规律。

增量式并不天然比位置式更高级。它需要保留过去误差和测量，而且处理限幅后，两种实现不一定仍完全等价。

## 2. 本篇采用的公式

```text
delta_P = Kp*(e[k]-e[k-1])
delta_I = Ki*dt*e[k]
delta_D = -Kd/dt*(y[k]-2*y[k-1]+y[k-2])
u[k] = clamp(u[k-1]+delta_P+delta_I+delta_D)
```

D对测量做二阶差分，是因为位置式的D已经是一阶测量差分；再计算“本次D减上次D”，自然得到二阶差分。不能把它误以为本控制器直接控制测量的二阶导数。

## 3. 公式怎么从位置式得到

先写出相邻两次P：Kp*e[k]和Kp*e[k-1]，相减得到delta_P。

积分项每次只多出Ki*dt*e[k]，因此delta_I不需要再求和。

微分项分别为-Kd*(y[k]-y[k-1])/dt和-Kd*(y[k-1]-y[k-2])/dt，相减就得到代码中的delta_D。

这里用的是固定dt。如果采样周期变化，两个微分分母不再相同，不能继续照搬这个式子。因此函数检测到周期改变会返回失败，而不是悄悄使用不一致的历史。

## 4. 状态字段

output保存上一次实际限幅输出；previous_error保存上次误差；previous_measurement和older_measurement保存两次测量；dt保存初始周期；initialized说明历史是否有效。

初次调用时旧误差取0，让P形成合理初始变化；两个旧测量都取当前测量，使首次D为0。这里假设初始输出为0；若执行器原来有非零输出，初始化和无扰切换应另行处理。

## 5. 对照代码顺序

先验证参数。本实现明确要求derivative_tau=0，因为没有推导带微分滤波的增量状态方程；传非零会返回失败，而不是忽略参数。

随后读取历史到局部变量，计算delta_P/I/D，再把候选输出限制到minimum/maximum。最后移动历史：旧previous_measurement成为older_measurement，当前测量成为previous_measurement。

这个移动顺序很重要。如果先覆盖previous_measurement，二阶差分就会混入当前值。

## 6. 手算例子

Kp=2、Ki=1、Kd=0、dt=0.1、初始输出0。

第一次误差为1：

```text
delta_P=2*(1-0)=2
delta_I=1*0.1*1=0.1
u=2.1
```

第二次误差变成0.5：

```text
delta_P=2*(0.5-1)=-1
delta_I=0.05
u=2.1-1+0.05=1.15
```

位置式在同一条件下得到P=1、累计I=0.15，同样为1.15。

## 7. 饱和与噪声边界

状态保存限幅后的输出，避免另有一个看不见的未限幅输出持续增长。但这不等于解决所有抗饱和问题，尤其驱动还有额外限流、串级约束或切换控制模式时。

二阶测量差分对噪声敏感。这篇用于理解基本离散关系；有噪声的实测通常更适合从带微分滤波的位置式开始。输出限制生效时，不应继续宣称两种PID逐点等价。
