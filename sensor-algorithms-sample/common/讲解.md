# 公共数学代码怎么读

前两份头文件复用数学基础，pid_core.h复用PID控制核心，均不包含传感器或执行器驱动。每个算法目录仍有独立 main 和讲解。

## math3d.h

统一约定：右手坐标系，机体 X前/Y左/Z上；姿态为机体到世界，Hamilton 四元数顺序 [w,x,y,z]。世界 Z 向上，静止比力为 +g；角度 rad，角速度 rad/s，时间 s。磁航向示例以磁北为世界X正向、磁西为Y正向；里程计以启动方向为X正向，不自动对准北。

| 类型或函数 | 做什么 | 调用条件 |
| --- | --- | --- |
| Vec3 | 保存 x/y/z 三个分量 | 分量使用同一种单位 |
| Quat | 保存 w/x/y/z 四个分量 | 旋转用途通常需单位化 |
| vec_norm | 求向量长度 | 有限测量值 |
| vec_unit | 方向归一化 | 长度不能接近零，失败不写输出 |
| vec_cross | 求叉积 | 顺序不能交换 |
| quat_normalize | 四元数归一化 | 拒绝无效长度 |
| quat_conjugate | 向量部分变号 | 只有单位四元数时才等于逆 |
| quat_multiply | Hamilton 乘法 | 不保证交换顺序结果相同 |
| quat_rotate | q*[0,v]*q共轭 | 调用者保证 q 已归一化 |
| quat_from_euler | 从 Z-Y-X 欧拉角构造姿态 | 有限弧度输入 |
| quat_step | 用机体系角速度增量更新 | dt>0，失败保留原姿态 |
| clamp_value | 限制到区间 | 用于已验证有限的数值 |

以旋转向量为例：body=[1,0,0]，q绕Z转90°。先构造 pure=[0,1,0,0]，再计算 q*pure*q共轭，向量部分得到[0,1,0]。反向变换使用共轭q旋转。

本批使用 double 便于检查数值。移植 MCU 时可改成 float，但必须重新核对极小量阈值、精度和性能；不要只替换类型后默认测试结论仍然成立。

## biquad.h

Biquad 中 b0/b1/b2 是前馈系数，a1/a2 是已归一化反馈系数，z1/z2 是历史状态。

每次更新：
```text
y = b0*x + old_z1
new_z1 = b1*x - a1*y + old_z2
new_z2 = b2*x - a2*y
```

先在局部变量计算三个新量，再一起写回。output 不应指向 state 的内部成员。初次必须调用 biquad_design 成功后再更新，不能把未初始化的结构体交给 update。

notch=0 设计低通，notch非0设计陷波。低通示例固定Q=1/√2；如果自行改变Q，就不再是这一标准二阶Butterworth响应。

## C 语法提示

- #ifndef/#define/#endif 避免同一头文件被重复展开。
- static inline 使小函数可在各个源文件内使用，不需要另编译一个库；inline并不保证编译器一定展开。
- *state=next 复制结构体所有字段；代码上的最后写回不代表中断或多线程意义上的原子操作。
- (Vec3){0,0,0} 是 C99 复合字面量，创建一个临时结构体值。
- size_t 适合长度和下标，是无符号类型，不要让它从0继续减1。

公共函数并不检查所有“物理上不可能”的输入，算法接口假设调用者遵守单位、缓冲区大小和初始化要求。无效数值检查不能替代这些条件。

## pid_core.h：位置式PID公共核心

PidConfig保存Kp/Ki/Kd、微分滤波时间常数和真实输出上下限；PidState保存积分贡献、旧测量、滤波微分和初始化标志。每个控制环各自维护状态，用{0}初始化一次。

pid_update先计算误差和滤波测量微分，再试算积分和前馈+反馈总输出。如果积分会使饱和更严重，就取消该次积分，最后限幅并写回。失败返回0且不修改状态和输出。

完整公式、单位和手算见 [位置式PID讲解](../23_pid/讲解.md)。这里与四元数数学库互相独立，不需要姿态头文件。控制仿真也不要求真实传感器输入。
