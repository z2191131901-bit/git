# 第 1 篇：陀螺仪读数怎样变成四元数姿态

这是一份用来确认讲解和代码风格的入门样稿。对应代码：`gyro_quaternion.c`。

## 1. 先弄清输入和输出

陀螺仪告诉你“现在转得多快”，不会直接告诉你“现在朝哪里”。

例如，物体始终绕同一根轴以 90 度/秒旋转，持续 1 秒，就转过了 90 度。算法的工作，就是把一次次采样之间的旋转累积到已有姿态上。

输入是三轴角速度和采样间隔；输出是描述当前朝向的四元数。它不计算位置，也不计算移动距离。

| 变量 | 含义 | 单位 |
| --- | --- | --- |
| `gyro_x` | 绕机体 X 轴的角速度 | rad/s |
| `gyro_y` | 绕机体 Y 轴的角速度 | rad/s |
| `gyro_z` | 绕机体 Z 轴的角速度 | rad/s |
| `dt` | 本次与上次采样的时间间隔 | s |
| `q` | 从机体坐标系到世界坐标系的姿态 | 无单位 |

机体坐标系跟着传感器转，世界坐标系是选定的固定参考系。两者均使用右手坐标系：右手大拇指指向某轴正方向，四指弯曲的方向就是绕该轴旋转的正方向。

## 2. 四元数的四个数是什么意思

写作 `q = [w, x, y, z]`。它们共同表示一次空间旋转，不能把 x、y、z 分别当成横滚角、俯仰角、偏航角。

如果旋转轴是单位向量 `[ux, uy, uz]`，旋转角度为 θ，那么：

```text
w = cos(θ / 2)
x = ux × sin(θ / 2)
y = uy × sin(θ / 2)
z = uz × sin(θ / 2)
```

绕 Z 轴旋转 90°，对应约 `[0.707107, 0, 0, 0.707107]`。没有旋转时对应 `[1, 0, 0, 0]`。

这里把初始方向当作参考方向。因此，初始化为单位四元数并不代表传感器已经找到了水平面或正北方向。姿态四元数的长度应为 1；q 和 -q 表示同一个旋转。

## 3. 角速度怎样改变四元数

采用 Hamilton 四元数乘法、机体到世界的旋转约定，并使用机体坐标系角速度时：

```text
q_dot = 0.5 × q ⊗ [0, gyro_x, gyro_y, gyro_z]
```

`q_dot` 是四元数变化率；`⊗` 表示四元数乘法。代码中四行 `derivative_*` 就是这条公式的展开。公式中的 0.5 与四元数采用半角表达有关。

随后使用最直接的一阶欧拉积分：

```text
新四元数 ≈ 旧四元数 + 四元数变化率 × dt
```

注意，“欧拉积分”是数值积分方法，与“欧拉角”不是同一个概念。

这一步把短时间内的变化率近似看成不变。每次采样转过的角度越小，通常越准确；高转速或过长采样间隔会增大误差。后续可以再学习增量四元数或更高阶积分。

公式和不同实现的约定可能不同。交换四元数顺序、使用世界到机体的姿态，或者改变乘法定义，都不能直接照搬这四行公式。

## 4. 对照代码读四个步骤

### 第一步：保存旧姿态

`old_w`、`old_x`、`old_y`、`old_z` 保存更新前的四个分量。

不能先修改 `q->w`，然后在计算其他分量时继续读取它。否则会把新旧两个时刻的数据混在一起。

### 第二步：计算变化率

先看容易理解的情形：初始姿态为 `[1,0,0,0]`，只有 `gyro_z` 不为零。

代入公式后，最初只有 `derivative_z = 0.5 × gyro_z` 不为零。因此第一次更新主要改变 z 分量；旋转继续累积后，w 也会变化。

### 第三步：乘以时间并累加

`next.z = old_z + derivative_z * dt` 表示把本次采样间隔内的变化加到旧值上。其他三个分量采用相同方式。

100 Hz 的理想采样周期为 `1 / 100 = 0.01` 秒。接真实硬件时应使用时间戳差值，或由可靠的固定采样机制保证这个周期。

### 第四步：归一化

```text
长度 = sqrt(w² + x² + y² + z²)
各分量分别除以长度
```

归一化让四元数重新满足长度为 1 的要求。它只修正长度，不能消除陀螺仪零偏，也不能把错误方向自动转回正确方向。

## 5. 运行示例

代码使用 C99 标准库，无第三方依赖。在本目录中，使用 GCC 可以编译：

```sh
gcc -std=c99 -Wall -Wextra -pedantic gyro_quaternion.c -lm -o gyro_quaternion
```

Linux/macOS 下运行 `./gyro_quaternion`；Windows 下运行 `./gyro_quaternion.exe`。

程序模拟绕 Z 轴以 90 度/秒旋转 1 秒。理论四元数为：

```text
w≈0.707107, x=0, y=0, z≈0.707107
```

一阶积分结果会有小误差。程序包含对这个已知结果的误差检查；失败时返回非零退出码。这只是演示检查，不是完整测试集。

当前编写环境的终端无法启动，因此这份样稿尚未实际编译运行，上面的数值是理论参考结果。

## 6. 接传感器之前要处理什么

1. 原始寄存器读数要按量程灵敏度换算。若得到的是度/秒，还要乘以 `π / 180` 转成弧度/秒。
2. 三个通道必须与选定的机体坐标轴一致，注意安装方向和正负号。
3. 如果测得静止零偏，先用当前角速度减去零偏，再进行积分。
4. `dt` 使用秒，例如 10 毫秒应传 `0.01f`，不能传 `10`。
5. 更新函数返回失败时，示例直接停止；硬件程序需要自行决定如何处理异常样本。

函数要求输入姿态是有效的单位四元数。示例提供基本的非法数值检查，但没有实现传感器量程、采样丢失等硬件异常判断。

## 7. 为什么静止时姿态还是会慢慢变

如果陀螺仪实际静止，却始终多报一点角速度，积分就会把这点误差不断累积成姿态误差。纯陀螺仪积分不能长期保持准确。

后续可以先学静止零偏估计，再学低通滤波、互补滤波，最后学习 Mahony 或 Madgwick 姿态融合。加速度计在适当运动条件下可以提供重力方向约束，但仅靠重力不能确定绕竖直方向的航向；航向通常需要磁力计或其他外部参考。

本例每次更新的计算量和额外存储量都是固定的，时间复杂度与空间复杂度均为 O(1)。
