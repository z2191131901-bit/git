# 第三批控制算法验证记录

## 环境与验证范围

Windows、MinGW-w64 GCC 8.1.0，使用现有verify.ps1，以C99和-Wall -Wextra -Werror -pedantic编译，每个示例独立执行。28个示例全部通过。随后补充PID微分低通手算检查、MPC解析代价值检查，仅重新编译运行这两个变更示例，也均通过。

编译产物写入系统临时目录，没有提交二进制文件。代码未连接真实电机或其它执行器，本记录为确定性仿真与边界检查。

## 本批六个示例

| 算法 | 验证内容 |
| --- | --- |
| 位置式PID | 手算输出2.1、积分抗饱和、设定值无D冲击、测量D符号、微分低通、闭环跟踪、非法dt |
| 增量式PID | 不饱和时与同离散形式的位置式一致、闭环跟踪、固定周期检查 |
| 串级PID | 外环速度限幅、内环命令限幅、位置与速度收敛、超调范围 |
| 前馈+P | 与同对象纯P比较最终值和累计绝对误差 |
| LQR | Riccati收敛、闭环谱半径、Bellman残差、非零初值收敛、非法权重拒绝 |
| MPC | 平衡输入、输入饱和、状态约束、无可行解、3个解析代价值、网格交叉检查、滚动闭环 |

## 如何理解结果

这些算法的仿真对象不完全相同，因此不能把上述数值当作PID、LQR、MPC之间的性能排名。

LQR是无约束双积分模型，MPC是带输入与预测状态约束的一维两步模型。MPC参考平衡输入依赖模型，不含未知扰动估计；仿真可行不代表真实系统的硬约束必然满足。

实际落地需要核对模型、执行器能力、采样时间、传感器延迟与测量噪声。当前没有实时运算时延、硬件在环或极端工况验证。

## 运行

在sensor-algorithms-sample目录中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./verify.ps1
```

Bypass仅作用于这一进程，不修改永久执行策略。各篇也提供单文件GCC命令。
