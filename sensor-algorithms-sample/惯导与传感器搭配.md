# 惯导与传感器搭配：从两个传感器到组合导航

本批新增三篇独立 C 示例，代码均有中文注释，讲解单独成文。
从容易接小车的版本开始，再逐步看三维惯导与多传感器融合。

| 阅读顺序 | 示例 | 实际完成的内容 |
| --- | --- | --- |
| 35 | [编码器＋陀螺仪](35_encoder_gyro/讲解.md) | 轮子给距离，陀螺仪给转角，更新平面位置 |
| 36 | [三维捷联惯导](36_strapdown_ins/讲解.md) | 三轴陀螺仪＋加速度计，更新四元数、速度、位置 |
| 37 | [多传感器EKF](37_navigation_ekf/讲解.md) | 平面IMU预测＋轮速＋磁航向＋外部位置，估计陀螺仪零偏 |

## 1. 编码器＋陀螺仪就够了吗

如果目标是短距离小车运动估计，可以先从第35篇开始。
编码器提供行程，陀螺仪提供航向变化，结果相对初始位姿计算。

它没有绝对位置，也没有绝对航向。
轮径误差、打滑和陀螺仪零偏会累积，不会因为用了两个传感器就自然消失。
加入外部位置/方向参考，才有机会持续校正对应漂移。

## 2. 除了这两个，还可以用哪些传感器

| 新增传感器/模块 | 能提供的信息 | 主要注意点 | 本仓库覆盖方式 |
| --- | --- | --- | --- |
| 加速度计 | 比力，经姿态和重力补偿后预测速度 | 零偏、倾斜误差、两次积分漂移 | 第36篇三维递推，第37篇前向加速度预测 |
| 磁力计 | 经校准和补偿后的航向 | 电机/铁件干扰、磁偏角、安装方向 | 第16/17篇预处理，第37篇航向观测 |
| GNSS/RTK定位模块 | 地理位置，某些模块还输出速度 | 遮挡、多路径、坐标转换、杆臂 | 第37篇接收转换后的局部 x/y；不实现接收机和坐标转换 |
| UWB定位模块 | 基站系位置或原始距离 | 基站布局、非视距偏差、坐标对齐 | 第37篇接收已解算 x/y；未实现原始测距定位 |
| 视觉定位/VIO模块 | 位姿或速度，取决于输出 | 光照、纹理、尺度、延迟、信息相关性 | 可使用第37篇位置/航向接口；未实现视觉前端 |
| 激光定位/SLAM模块 | 相对或地图系位姿 | 地图匹配退化、坐标对齐、延迟 | 可使用第37篇位置/航向接口；未实现点云匹配 |
| 气压计 | 压力变化对应的相对高度信息 | 天气、温度、气流、参考压力变化 | 本批仅讲选用方式，尚无高度融合代码 |
| 测距雷达/激光/超声波 | 沿波束到表面的距离 | 倾斜、反射、目标表面、安装高度 | 本批未实现距离观测模型 |
| 光流＋测高 | 结合尺度后的地面相对速度 | 纹理、距离、相机转动补偿 | 本批未实现光流处理或观测模型 |

上表区分“已写融合接口”和“已写传感器解算算法”。
例如有位置接口，不代表已经实现 GNSS 解算、UWB多边定位或视觉SLAM。

## 3. 怎么按设备条件选择

- 只有编码器和陀螺仪：读第35篇，先确认直行、转向、倒车和单位。
- 有完整六轴IMU：读第36篇理解比力、姿态、重力和速度积分；小车平面融合可再读第37篇。
- 有磁力计但无外部位置：可在第37篇保留轮速和航向更新、跳过 PX/PY；航向得到辅助，位置仍会漂移。
- 有外部位置但没有磁力计：可跳过 YAW 更新；运动时位置观测可能约束航向，静止时不能指望单点位置识别车头方向。
- 有位置、航向和轮速：第37篇主仿真就是这个组合，演示位置中断和异常测量。
- 没有编码器：可跳过 SPEED 更新，但前向速度更依赖加速度积分和位置校正，需重新验证模型与噪声参数。

上述删减调用说明接口如何工作；本批完整轨迹对比验证的是第37篇所列组合，
没有声称所有传感器子集都已做实车或统计验证。

## 4. 原始数据到融合器之间还有一层工作

~~~text
原始计数/寄存器/数据包
    ↓
时间戳、单位换算、比例/零偏校准、安装方向转换
    ↓
轮速 / 角速度 / 比力 / 磁航向 / 局部位置
    ↓
惯性预测与按时间戳到达的观测更新
    ↓
位姿、速度、不确定度
~~~

先处理这一层，再调滤波参数。
常见错误是陀螺仪 °/s 没转 rad/s，或者编码器毫米直接当米。
这些是单位错误，调大 Q 或 R 解决不了。

初始化也属于算法的一部分：初始位置、初始航向、初始速度、零偏和协方差需要合理设置。
“所有量都填零”只是特定场景下的假设，不是通用初始化方案。

## 5. 本批边界

第35篇是平面航位推算，第36篇是简化局部三维惯性递推，第37篇是五状态平面 EKF。
它们是逐步学习的三种实现，并非已连成一套完整三维 ESKF。
三维误差状态融合、气压计高度、原始UWB距离融合、视觉/激光前端仍可后续单独扩展。

全部示例采用模型数据，编译及仿真结果见 [惯导融合验证](惯导融合验证.md)。
