# Mahony：用方向误差修正陀螺仪

对应代码：[mahony.c](mahony.c)。

## 1. 先理解它要解决的问题

先用陀螺仪描述旋转，再让重力相关方向和可选磁场方向把姿态往正确方向拉回。核心是三维向量的叉积反馈，而不是把三个欧拉角分别相加。

## 2. 输入、输出与约定

gyro 为 rad/s，dt 为秒。accel 是机体系比力，水平静止为 +Z，函数内部归一化方向。mag 可选；magnetic_world 是已知或标定好的世界磁场方向，必须与世界坐标定义一致。两个 valid 标志由上层决定。

## 3. 公式先看懂每个量

```text
predicted_up = R(q)^T * [0,0,1]
error = measured_up × predicted_up
若磁场可信，再加 measured_mag × predicted_mag
integral += ki*error*dt
corrected_rate = gyro + kp*error + integral
用 corrected_rate 更新四元数
```

## 4. 按执行顺序读代码

### 第 1 步：保存姿态和积分项

Mahony 包含 q 与 integral。q 初始化为单位或已知姿态，integral 初始化为零。integral 在采样间持续保存，代表负零偏方向的角速度校正。

### 第 2 步：预测参考方向

q 是机体到世界，所以预测世界向上方向在机体中的投影要用共轭 q 旋转。把这个方向与归一化加速度比较。

### 第 3 步：用叉积形成误差

measured×predicted 的大小与夹角的正弦有关，方向提供校正旋转轴。顺序反过来会把负反馈变成正反馈。

### 第 4 步：增加可选磁场约束

磁场也先归一化，幅值不直接参与误差。参考磁场如果几乎竖直，不能提供可靠航向，因此拒绝。这个版本要求已知 magnetic_world，不自动查当地地磁模型。

### 第 5 步：比例与积分

kp 直接放大当前方向误差；ki 把误差随时间累积。ki=0 时明确清零积分项。没有可信观测时保留已有积分校正，但不继续积累。

### 第 6 步：防饱和与更新

每轴积分项限制在 ±0.5 rad/s，再通过公共增量函数更新姿态。该限值只是本例参数，应按真实陀螺仪误差配置。

## 5. 代入数字算一次

初始姿态误以为横滚 +10°，真实设备水平。预测向上方向约 [0,0.17365,0.98481]，测量为 [0,0,1]。测量×预测得到 X 误差 -0.17365。kp=2 时产生约 -0.3473 rad/s 校正，方向会把正横滚误差减小。

## 6. 参数怎样选

kp 大通常收敛快，但也会更信受运动污染的加速度。ki 用于缓慢偏差估计，应先让 kp 工作稳定，再调 ki。采样时间不能遗漏，否则积分项量纲和强度都错误。

## 7. 常见错误与适用边界

只有加速度方向不能确定绝对航向；六轴版本不能消除所有轴在所有运动下的零偏。平动时加速度不等于纯参考方向，需降低权重或置为不可信。180° 反向初始方向可能使叉积为零，不能承诺任意初值都快速收敛。本例磁场等权叠加，没有完整磁异常检测。

## 8. 示例验证了什么

验证静止横滚误差收敛、加入已知水平磁场后的航向收敛、恒定 X 轴零偏的积分校正收敛、零加速度被标记有效时拒绝。更新 O(1)，存储 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic mahony.c -lm -o mahony
```

Windows 运行 ./mahony.exe；Linux/macOS 运行 ./mahony。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
