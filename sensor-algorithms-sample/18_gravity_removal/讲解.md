# 坐标变换与重力去除：得到世界系运动加速度

对应代码：[gravity_removal.c](gravity_removal.c)。

## 1. 先理解它要解决的问题

加速度计的静止读数并不是零。要得到运动加速度，必须先知道姿态，把机体系比力旋转到世界系，再加上真实重力加速度。

## 2. 输入、输出与约定

q为机体到世界，输入specific_force单位m/s²，世界Z向上。静止水平比力为[0,0,+g]，世界真实重力为[0,0,-g]。不能把芯片已经去重力的linear acceleration再送进来重复扣除。

## 3. 公式先看懂每个量

```text
比力模型：f_body = R(q)^T*(a_world-g_world)
因此：a_world = R(q)*f_body + g_world
世界Z向上时：a_world.z = rotated_force.z - g
```

## 4. 按执行顺序读代码

### 第 1 步：验证并归一化姿态

q按值传递，函数归一化副本。全零四元数无效，返回失败。

### 第 2 步：旋转三轴数据

quat_rotate 使用q*[0,f]*q共轭得到世界系比力。不能只减机体Z轴的g，因为倾斜时重力相关分量分布在多个轴。

### 第 3 步：减去世界Z的g

旋转后的静止比力为+g，世界真实重力为-g，所以world.z-=gravity。这个减号来自选定世界轴约定，不是所有资料都通用。

### 第 4 步：检查结果再返回

若计算溢出就返回失败，否则写入Vec3输出。调用时out是结构体地址，使用&acceleration传入。

## 5. 代入数字算一次

水平静止时输入[0,0,9.80665]，旋转不变，减去Z上的9.80665得到[0,0,0]。世界向前加速2时，世界比力为[2,0,g]，扣除后得到[2,0,0]。自由落体的比力近零，输出却应为[0,0,-g]。

## 6. 参数怎样选

gravity需与单位和当地重力模型一致。姿态与加速度要时间同步，否则快速转动时即使两个单独测量都正确，组合后也会出现假加速度。

## 7. 常见错误与适用边界

姿态误差会让重力泄漏到水平加速度。仅1°倾角误差就可能引入约g*sin1°≈0.171m/s²的误差，积分速度和位置会持续漂移。因此本篇没有承诺仅靠IMU双积分就得到可靠位置。

## 8. 示例验证了什么

检查任意倾斜姿态的静止结果为零、已知世界加速2m/s²恢复、自由落体向下g，以及无效四元数拒绝。时间与存储O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic gravity_removal.c -lm -o gravity_removal
```

Windows 运行 ./gravity_removal.exe；Linux/macOS 运行 ./gravity_removal。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
