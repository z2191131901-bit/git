# 单轴互补滤波：陀螺仪负责预测，倾角负责校正

对应代码：[complementary.c](complementary.c)。建议先读零偏、倾角和一阶低通三篇。

## 1. 为什么要融合
陀螺仪给出角速度，乘时间就能预测角度变化，响应快但积分误差会累积。加速度计在静止或低动态条件下能提供倾角参考，却容易被平动和振动干扰。

本例把两者结合，演示一个绕固定 X 轴旋转的横滚模型。任意三维运动时，机体系 gyro_x 不一定等于横滚角变化率，不能简单复制三个单轴滤波器就声称实现了完整三维姿态融合。

## 2. 输入输出和状态
| 变量 | 含义 | 单位 |
| --- | --- | --- |
| gyro_rate | 已去零偏的 X 轴角速度 | rad/s |
| accel_angle | 加速度计算出的横滚参考角 | rad |
| accel_valid | 这次参考角是否可信 | 布尔意义 |
| tau | 校正时间常数 | s |
| dt | 与上次更新的时间间隔 | s |
| angle | 持续保存的融合角度 | rad |

输出留在 state->angle。初始化使用 Complementary filter={0}；第一条可信参考角定义起点，后续才积分相邻采样间的变化。

## 3. 先看没有跨角度边界的公式
```text
预测角 = 旧角 + 角速度 × dt
alpha = tau/(tau+dt)
融合角 = alpha × 预测角 + (1-alpha) × 加速度计角
```
换一种等价写法：
```text
beta = 1-alpha = dt/(tau+dt)
误差 = 加速度计角 - 预测角
融合角 = 预测角 + beta × 误差
```
代码选择第二种形式，便于处理角度环绕。

## 4. 手算一轮
旧角为 0，gyro_rate=0.1 rad/s，dt=0.01 秒，参考角为 0，tau=0.5 秒：
```text
预测角 = 0 + 0.1×0.01 = 0.001 rad
beta = 0.01/(0.5+0.01) ≈ 0.019607843
误差 = 0-0.001 = -0.001 rad
新角 = 0.001 + 0.019607843×(-0.001)
     ≈ 0.000980392 rad
```
可以看到，参考角只把预测结果往零拉回了一小步，没有直接覆盖它。

## 5. 为什么要处理 ±180° 边界
当前预测为 +179°，参考角为 -179°，两者其实只相差 2°。直接相减得到 -358°，会让滤波朝错误的长路径移动。

wrap_angle 用 remainder(angle,2π) 找到 [-π,π] 内的等效角。于是误差由 -358° 变成 +2°。若 beta=0.5，校正后落在约 ±180°，而不是错误地跑到 0°。

remainder 是 C 数学库函数，不是整数的 % 运算。π 与 -π 是同一边界方向，演示检查因此比较绝对值。恰好相差 180° 时最短方向本来就不唯一。

## 6. 对照更新函数
先检查时间、参数和必要的测量是否为有限数。
尚未初始化时必须得到可信倾角；没有它就返回失败。
初始化后先积分角速度，得到 next。
只有 accel_valid 为真才计算倾角误差并校正；否则只保留预测。
最后写回 state->angle。

accel_valid 为假时允许 accel_angle 为 NaN，因为它不会参与计算。这个标志需要上层依据运动状态判断，本示例没有悄悄把所有加速度都当成可信数据。

## 7. 参数与局限
tau 大：每次拉回得少，更信陀螺仪，校正慢。
tau 小：参考角影响更大，更容易把振动或平动误差引入姿态。

不要说互补滤波能彻底消除陀螺仪零偏。在这个离散模型中，静止、参考角为零、残余零偏为 b 时，稳态角误差为 tau×b。例如 tau=0.5 秒、b=0.02 rad/s，最终误差约 0.01 rad。因此仍应先标定零偏。

没有可信倾角时只能预测，持续时间越长越可能漂移。滤波不会凭空创造缺失的参考信息。

## 8. 示例检查了什么
main 检查无参考时不能初始化、首值初始化、手算结果、非法 dt 不改变状态、临时丢失观测时的纯预测、跨 ±180° 和残余零偏的稳态误差。

单次更新 O(1)，额外存储 O(1)。硬件接入时需保证倾角和角速度方向一致，且时间对应同一采样时刻。

## 9. 编译与参考
```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic complementary.c -lm -o complementary
```
Windows 运行 ./complementary.exe，Linux/macOS 运行 ./complementary。

原理参考：[AHRS Complementary Filter](https://ahrs.readthedocs.io/en/latest/filters/complementary.html)。本代码独立编写，额外显式处理了角度环绕及无效参考观测。
