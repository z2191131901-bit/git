# 四元数转欧拉角：把姿态变成直观读数

对应代码：[euler_angles.c](euler_angles.c)。

## 1. 先理解它要解决的问题

四元数适合内部计算，但人更容易理解横滚、俯仰和偏航。本篇用于显示或记录，内部姿态仍建议保留四元数。

## 2. 输入、输出与约定

输入遵守公共机体到世界约定，输出 Euler.roll/pitch/yaw 均为弧度。采用 Z-Y-X 旋转，即 R=Rz(yaw)Ry(pitch)Rx(roll)。pitch 输出主值在 [-π/2,π/2]。

## 3. 公式先看懂每个量

```text
roll  = atan2(2*(w*x+y*z), 1-2*(x²+y²))
pitch = asin(2*(w*y-z*x))
yaw   = atan2(2*(w*z+x*y), 1-2*(y²+z²))
以上为非奇异情况；奇异点需选定一个等价表示。
```

## 4. 按执行顺序读代码

### 第 1 步：规范输入

q 按值传入，函数只归一化自己的副本。output 是结果地址，必须有效；零四元数返回失败。

### 第 2 步：限制反正弦输入

数学上 sin_pitch 必须在 [-1,1]，浮点运算可能略超界。clamp_value 限制范围后再 asin，避免 NaN。

### 第 3 步：普通分支

atan2 接收分子分母的独立符号，因此能判断象限，不应换成 atan(分子/分母)。

### 第 4 步：奇异分支

pitch 约 ±90° 时，roll 和 yaw 不能唯一拆开。本例固定 roll=0，再由旋转矩阵元素算一个等价 yaw。阈值附近显示值可能跳变，不能据此认定姿态突然变化。

### 第 5 步：一次返回三个结果

局部 next 保存三个角，全部算好后 *output=next。Euler 结构体让三个输出保持成组。

## 5. 代入数字算一次

输入只绕 Z 转 90° 的 q≈[0.707107,0,0,0.707107]，sin_pitch=0，roll=0；yaw 的 atan2 分子为 1，分母为 0，因此 yaw=π/2。换成度乘 180/π，得到 90°。

## 6. 参数怎样选

这里的 1e-10 是靠近欧拉角奇异点的数值判断阈值，不是传感器噪声参数。若应用需要连续角度显示，还要另外实现航向展开，不能把 [-π,π] 的边界跳跃当成实际旋转。

## 7. 常见错误与适用边界

四元数避免了内部表示的欧拉角奇异，但一旦转换为欧拉角，奇异性仍然存在。接近奇异点时各角可能不稳定，重建的整体旋转更值得检查。

## 8. 示例验证了什么

验证混合姿态 [0.2,-0.3,0.7] 的三角恢复，以及 pitch 为 ±90° 时重建姿态与输入等价。用四元数点积绝对值处理 q/-q 等价性。复杂度 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic euler_angles.c -lm -o euler_angles
```

Windows 运行 ./euler_angles.exe；Linux/macOS 运行 ./euler_angles。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
