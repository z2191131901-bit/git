# 四元数基础：四个数怎样表示旋转

对应代码：[quaternion_basics.c](quaternion_basics.c)。

## 1. 先理解它要解决的问题

这是后续姿态算法共同使用的数学基础。先弄懂四元数怎样相乘、怎样反向旋转，再去看融合算法里的误差校正。主要实现放在 ../common/math3d.h，本目录 C 文件提供能运行的例子。

## 2. 输入、输出与约定

四元数顺序为 [w,x,y,z]，采用 Hamilton 乘法，表示机体坐标系到世界坐标系的旋转。单位四元数长度为 1；角度使用弧度。Vec3 表示三维向量，不与四元数混用。

## 3. 公式先看懂每个量

```text
绕单位轴 [ux,uy,uz] 转 theta：
q = [cos(theta/2), ux*sin(theta/2), uy*sin(theta/2), uz*sin(theta/2)]
共轭 q* = [w,-x,-y,-z]
单位四元数的逆 = 共轭
旋转向量 v：v_world = q * [0,v_body] * q*
```

## 4. 按执行顺序读代码

### 第 1 步：先看类型

typedef struct 把四个相关的 double 放进 Quat。double 提供更高的浮点精度，便于核对学习示例。q.w 访问结构体变量，q->w 通过指针访问结构体，两种写法不要混淆。

### 第 2 步：再看归一化

quat_normalize 用 hypot 计算长度，把四个分量分别除以长度。先验证长度有效，才开始写回。全零四元数没有旋转意义，函数返回 0；不能把它当作“没有旋转”，无旋转应为 [1,0,0,0]。

### 第 3 步：理解乘法

quat_multiply 的标量部分是 aw*bw 减去两个向量的点积，向量部分还包含叉积。加减号和顺序来自 Hamilton 定义，不是可调参数。两个输入按值传入，因此计算不会覆盖调用者数据。

### 第 4 步：理解共轭与向量旋转

把三维向量临时写成标量为零的纯四元数，做 q*v*q*，最后取结果的 x/y/z。quat_rotate 要求 q 已经归一化；如果省略条件，结果可能被错误缩放。

### 第 5 步：理解旋转次序

对固定坐标轴，先做 qx，再做 qz，复合旋转为 qz*qx，右侧先作用。后续机体系增量右乘当前姿态，描述的是另一种明确约定，不能仅凭“先后”口号混用。

## 5. 代入数字算一次

绕 Z 轴转 90°：半角为 45°，q≈[0.707107,0,0,0.707107]。把 [1,0,0] 送入 quat_rotate，得到 [0,1,0]。再用共轭旋转回来，就得到原来的 X 方向。这可以拿右手拇指指向 +Z 来检查。

## 6. 参数怎样选

这篇没有滤波参数。真正需要统一的是旋转方向、分量顺序和角度单位。atan/sin/cos 接收弧度，90° 应换成 π/2。

## 7. 常见错误与适用边界

q 和 -q 表示同一姿态，不能仅比较四个分量是否完全相等来判断方向不同。乘法一般不满足交换律；共轭仅在单位四元数条件下等于逆。代码按有效传感器量级设计，不作为任意极端数值的通用代数库。

## 8. 示例验证了什么

示例检查归一化、q*q* 为单位、X 转到 Y、交换乘法顺序结果不同、零四元数被拒绝。每个操作计算量 O(1)，额外存储 O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic quaternion_basics.c -lm -o quaternion_basics
```

Windows 运行 ./quaternion_basics.exe；Linux/macOS 运行 ./quaternion_basics。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
