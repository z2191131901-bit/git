# 二阶 Butterworth：用两个状态实现低通

对应代码：[butterworth.c](butterworth.c)。

## 1. 先理解它要解决的问题

一阶低通之后，可以学习衰减更快的二阶低通。本例先设计系数，再逐个样本更新。公共 biquad.h 给出完整设计和计算，当前文件用信号验证频率响应。

## 2. 输入、输出与约定

fs为采样率Hz，frequency为截止频率Hz，必须0<frequency<fs/2。Butterworth的quality固定为1/√2。输入输出保持同一物理单位；z1/z2是跨采样保存的内部状态。

## 3. 公式先看懂每个量

```text
omega=2*pi*fc/fs
alpha=sin(omega)/(2*Q)，Q=1/sqrt(2)
未归一系数：
b0=(1-cos omega)/2，b1=1-cos omega，b2=b0
a0=1+alpha，a1=-2*cos omega，a2=1-alpha
全部系数除以a0，之后a0不再保存。
```

## 4. 按执行顺序读代码

### 第 1 步：初始化只做一次

biquad_design 计算系数并清零状态。不能每次采样都调用，否则历史反馈被清掉。换参数时也会出现重新初始化瞬态。

### 第 2 步：理解分母反馈

差分方程是 y=b0*x+b1*x_old+b2*x_older-a1*y_old-a2*y_older。分母系数前面的减号是本库约定，移植其它库时必须核对。

### 第 3 步：理解转置直接II型

当前 y=b0*x+z1；新z1=b1*x-a1*y+旧z2；新z2=b2*x-a2*y。这两个状态把过去输入和输出的影响压缩保存，不需要四个独立历史数组。

### 第 4 步：先算局部值再写状态

y、z1、z2都算成局部变量，检查有限后才写回，避免更新z1后错误地影响其它计算。

### 第 5 步：验证稳定性

设计时检查二阶分母的稳定条件，拒绝浮点舍入造成的极端退化参数。这个检查不能替代应用对采样率和频率单位的核对。

## 5. 代入数字算一次

fs=1000Hz，fc=50Hz时，omega≈0.314159，Q≈0.707107。归一后的系数约为b0=0.0200834、b1=0.0401667、b2=0.0200834、a1=-1.5610181、a2=0.6413515。初始z1=z2=0，输入1，第一步y≈0.0200834；之后反馈逐渐把恒定输入输出推向1。

## 6. 参数怎样选

截止频率越低，抑制高频越强，但响应更慢。二阶Butterworth的截止频率处幅值约为1/√2，即约-3dB。这里使用数字滤波设计公式，不是简单把连续参数直接塞进差分方程。

## 7. 常见错误与适用边界

滤波需要相对稳定的采样率。已经混叠到低频的干扰无法靠后置数字低通还原；采样前抗混叠仍重要。低通也会引入相位延迟和启动瞬态，不能只看曲线更平滑。

## 8. 示例验证了什么

模拟正弦并丢弃启动部分，测50Hz幅值约0.707107、400Hz明显衰减；恒定输入最后为1；NaN不破坏状态；截止设到奈奎斯特频率时拒绝。设计与更新O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic butterworth.c -lm -o butterworth
```

Windows 运行 ./butterworth.exe；Linux/macOS 运行 ./butterworth。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
