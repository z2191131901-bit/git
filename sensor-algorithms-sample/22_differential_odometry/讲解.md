# 差速里程计：左右轮距离怎样变成小车轨迹

对应代码：[differential_odometry.c](differential_odometry.c)。

## 1. 先理解它要解决的问题

差速小车靠左右轮不同速度转弯。已知两轮在一段采样内走过的距离，可以递推车体中心位置和朝向。这是相对里程计，不是GPS绝对定位。

## 2. 输入、输出与约定

left_distance/right_distance为同一时间段左右轮有符号行程m，track_width为两轮有效轮距m。世界X是起始前方、Y向左，yaw逆时针为正，单位rad。Pose2D={0,0,0}定义起始原点。

## 3. 公式先看懂每个量

```text
中心弧长 distance=(left+right)/2
转角 angle=(right-left)/track_width
弦长 chord=distance*sin(angle/2)/(angle/2)
中间朝向 middle=old_yaw+angle/2
new_x=old_x+chord*cos(middle)
new_y=old_y+chord*sin(middle)
new_yaw=old_yaw+angle
```

## 4. 按执行顺序读代码

### 第 1 步：先分解直行和转动

平均轮程决定中心运动量，左右差除轮距决定朝向变化。右轮走得更远时向左转，正转角符合本例坐标定义。

### 第 2 步：把弧长换成弦长

如果直接用中心弧长沿中间方向平移，较大转角时会产生几何误差。sinc项把弧长转换为两位置之间的直线距离。

### 第 3 步：处理直行极限

angle为0时sin(angle/2)/(angle/2)是0/0，但极限为1。代码用1-half²/6处理很小转角，直行因此自然退化为distance平移。

### 第 4 步：在中间方向分解

cos/sin把弦长分成世界X/Y增量。先使用旧yaw计算middle，然后再更新yaw，不能提前覆盖旧朝向。

### 第 5 步：限制角度表示

remainder把yaw放回[-π,π]，避免长期积累大角度。它只改变表示，不改变实际朝向；如果需要累计圈数要另存展开角。

## 5. 代入数字算一次

轮距0.5m，车中心沿半径1m左转90°。左轮半径0.75m，右轮1.25m，因此left=0.75π/2，right=1.25π/2。平均弧长π/2，转角π/2，弦长√2，方向45°，得到Δx=1、Δy=1、yaw=90°。

## 6. 参数怎样选

轮距应是实际有效轮距，轮半径在编码器转距离时使用。左右轮半径不一致也会使直行轨迹弯曲。这里使用距离增量所以不额外需要dt，但两个轮的增量必须覆盖同一时间段。

## 7. 常见错误与适用边界

假设无侧滑、平面运动、步内轮速比近似恒定。轮胎打滑、地面不平和参数误差都会积累漂移；长期定位需与IMU/GNSS/视觉等融合。函数没有估计协方差，也不是完整导航系统。

## 8. 示例验证了什么

验证直行1m、倒车回原点、原地旋转90°、半径1m四分之一圆到[1,1]、零轮距拒绝且旧状态不变。计算与存储O(1)。

main 中先调用算法，再用 assert 检查已知结果。assert 条件为假时程序停止；验证时不要定义 NDEBUG，否则会关闭这些检查。函数返回成功只说明完成了本次计算，不代表输入一定符合真实物理条件。

## 9. 编译与运行

在本目录执行：

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic differential_odometry.c -lm -o differential_odometry
```

Windows 运行 ./differential_odometry.exe；Linux/macOS 运行 ./differential_odometry。当前验证平台为 Windows GCC，未做硬件在环验证。

部分示例使用相对路径包含公共头文件，请保留目录结构。它们不依赖第三方库。也可在上级目录运行 verify.ps1，一次编译并执行全部独立示例。
