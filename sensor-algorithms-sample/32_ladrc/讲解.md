# 一阶线性 ADRC：把未知部分合成一个总扰动

对应代码：[ladrc.c](ladrc.c)。

## 1. 本篇具体是哪一种ADRC

这里实现一阶线性自抗扰控制LADRC：线性扩张状态观测器LESO，加上线性误差反馈和扰动补偿。

它不包含非线性fal函数、非线性跟踪微分器TD或高阶ADRC。先把最小闭环讲清楚，再考虑复杂版本，比把许多公式挤进一个函数更容易理解。

## 2. 如何看待未知对象

把对象写成：

```text
y_dot=b0*u+f
```

b0是名义输入增益，f把未知动力学、外部扰动和输入增益误差合在一起。

例如真实对象：

```text
y_dot=-a*y+b_actual*u+d
```

则：

```text
f=-a*y+(b_actual-b0)*u+d
```

因此z2估计的不是单独的外部d。把z2直接当成负载大小可能误解它。

## 3. 扩张状态为什么是两项

z1估计输出y，z2估计总扰动f。在短采样间隔内，先近似认为f不变：

```text
z1_predict=z1+dt*(z2+b0*u_previous)
z2_predict=z2
```

得到当前测量后：

```text
innovation=measurement-z1_predict
z1_new=z1_predict+l1*innovation
z2_new=z2_predict+l2*innovation
```

这就是代码的预测—校正顺序。使用上一周期真实输入，避免把尚未执行的新命令用来解释过去的运动。

## 4. 离散增益怎样配置

设观测器期望重复离散极点p=exp(-wo*dt)，本预测—校正形式对应：

```text
l1=1-p²
l2=(1-p)²/dt
```

这里wo是观测器带宽参数。把它和另一种连续ESO里的2*wo、wo²直接混用，会改变离散结构。

代码验证误差矩阵的迹等于2p、行列式等于p²，确认两个极点都为p。这只验证名义扩张模型的观测器配置，不是完整真实闭环鲁棒性证明。

## 5. 观测之后如何控制

希望输出误差按一阶规律衰减：

```text
desired_rate=wc*(reference-z1)
u_raw=(desired_rate-z2)/b0
```

wc是控制带宽参数。补偿项-z2抵消估计总扰动，desired_rate负责朝目标移动，最后把输出限制在执行器范围内。

初次没有历史，直接令z1=当前测量，z2=0，再计算输入。不能用默认z1=0去解释一个本来就很大的测量，否则可能出现较大的初始化冲击。

## 6. 手算观测器参数

本例dt=0.005、wo=20：

```text
p=exp(-0.1)≈0.904837
l1≈0.181269
l2≈1.811183
```

若当前预测比实测小0.01，则z1增加约0.00181269，z2增加约0.01811183。z1和z2单位不同：z1与y相同，z2与y的变化率相同。

## 7. 为什么示例中的总扰动是负数

控制器用b0=1；真实对象a=1.5、b_actual=0.8，外扰d=0.4。目标y=0.5时，维持输入为：

```text
u=(1.5*0.5-0.4)/0.8=0.4375
```

于是总扰动：

```text
f=-1.5*0.5+(0.8-1)*0.4375+0.4=-0.4375
```

虽然外扰是+0.4，z2却应接近-0.4375，两者并不矛盾。代码检查的正是这个已知稳态结果。

## 8. 参数和边界

本例wc=4、wo=20，不是通用最佳比例。wo太大容易放大噪声和采样误差；wc过大可能使输入长时间饱和。b0应有正确符号和合理量级，本实现只接受正作用b0>0。

总扰动需要在观测器可跟踪的时间尺度内变化。补偿不能突破执行器能力，也不能消除测量延迟。当前没有针对长时间饱和、动态切换与硬件故障的完整保护设计。

如果改变采样周期，必须重新设计l1/l2，并保证传入的previous_applied_input和measurement时刻一致。

## 9. 验证与编译

验证离散极点、真实输入增益与b0不同时的闭环收敛、阶跃扰动后的目标恢复、输出范围与非法测量保持状态。运行结果y=0.5，u=0.4375，z2=-0.4375。

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic ladrc.c -lm -o ladrc
```

运行 ./ladrc.exe。每次更新O(1)，无需通用矩阵库。参考：[pyadrc介绍](https://pyadrc.readthedocs.io/en/latest/introduction.html)，本代码按明确的一阶离散结构独立编写。
