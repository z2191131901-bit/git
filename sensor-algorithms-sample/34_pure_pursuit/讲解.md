# Pure Pursuit：盯住前方一点，用圆弧追过去

对应代码：[pure_pursuit.c](pure_pursuit.c)。仿真把上一篇A*的格子路径接入跟踪器。

## 1. 跟踪器需要哪些输入

需要有序路径点、机器人当前位置和朝向、前视距离，以及速度和角速度限制。

RobotPose的x/y单位m，yaw单位rad；机器人局部X向前、Y向左。输出velocity单位m/s、angular_velocity单位rad/s，对应差速/独轮车运动模型。

它不直接输出阿克曼车辆的转向角；该类车辆通常还需要轴距换算，且不能使用本例的原地转向恢复动作。

## 2. 前视点怎样选择

先把折线各段长度累计起来，得到每个点对应的路径弧长。然后在尚未走过的路径上寻找机器人位置的最近投影，作为当前progress。

目标弧长为progress+lookahead，超过全长则截到终点，再在线段中插值得到目标坐标。

本例按路径弧长前移，不是求前视圆与路径的交点。因此真正目标直线距离不一定等于lookahead，后面的曲率分母必须使用实际目标距离。

## 3. 怎样把位置投影到线段

设线段起点P，方向向量D，机器人为R：

```text
t = ((R-P)·D)/|D|²
投影 = P+t*D
```

t限制到[0,1]，保证点在线段上。再结合已走过progress设置更严格的下界，避免正常跟踪时回退到旧路径。

代码对未来各段都求距离，选择最近者。这适合本示例单次通过、间隔清楚的折线路径；自交、很接近的回折或并行段可能使进度跳到另一段，需要更严格的路径关联策略。

## 4. 世界目标怎样变到车体局部

```text
dx=target_x-robot_x
dy=target_y-robot_y
local_x=cos(yaw)*dx+sin(yaw)*dy
local_y=-sin(yaw)*dx+cos(yaw)*dy
```

如果目标在左侧，local_y为正，接下来应该产生正角速度，也就是逆时针左转。

这个变换使用负yaw旋转，因为要从世界系变回机体系。

## 5. 圆弧曲率怎么得到

设追踪圆经过机器人当前位置与目标点，且在当前位置切线沿车头方向：

```text
curvature = 2*local_y/(local_x²+local_y²)
angular_velocity = velocity*curvature
```

curvature单位1/m。目标正前方时local_y=0，曲率为0，直行；目标左侧时曲率为正。

这里不是对横向误差随便乘一个增益，而是利用圆的几何关系计算转弯曲率。

## 6. 手算一轮

机器人在(0,0)，朝向0；前视点是(1,1)：

```text
local_x=1，local_y=1
距离平方=2
curvature=2*1/2=1 m^-1
若速度0.6m/s，角速度0.6rad/s
```

这对应半径1m的左转圆弧。示例第一个测试核对的就是这个结果。

## 7. 限制角速度时为什么降低线速度

若保持曲率，但算出的角速度超过上限，可以把速度降低到max_angular_speed/abs(curvature)。这样仍保留规划的圆弧几何关系。

若只独立截断角速度而保持原线速度，实际曲率会变小，转弯路径就变了。

终点附近采用速度=min(max_speed,1s^-1*goal_distance)，逐渐减速；距离不超过tolerance后同时输出零速度和零角速度。

本例没有显式限制线加速度和角加速度，所以只是速度层面的几何跟踪，尚未生成完整平滑执行轨迹。

## 8. 目标跑到车后面怎么办

纯追踪假设前视目标在前方。当local_x<=0，本例差速机器人先输出零线速度，并按目标方向误差原地旋转，直到目标重新位于前方。

这是额外的恢复策略，不是标准曲率公式自身能解决的问题。阿克曼车辆不能原地旋转，必须换成适合车辆的恢复或重新规划策略。

## 9. 与A*如何连接

A*返回row*cols+col。每格1m时，格子中心转换为：

```text
x=col+0.5
y=row+0.5
```

示例从(1.5,1.5)出发，绕过col=3上的墙，到达(6.5,6.5)附近。前视0.6m，最大速度0.6m/s，最大角速度1.5rad/s，控制周期0.02秒。

使用理想的当前位置和朝向，不包含定位误差、电机响应延迟或轮胎打滑。

## 10. 仿真怎么更新机器人

一个周期内保持v/w不变，按圆弧精确更新：

```text
yaw_next=yaw+w*dt
x_next=x+(v/w)*(sin(yaw_next)-sin(yaw))
y_next=y+(v/w)*(cos(yaw)-cos(yaw_next))
```

w接近0时改用直线公式，避免除零。这和差速里程计篇的几何含义一致，只是这里输入的是速度命令。

## 11. 验证与安全边界

检查已知曲率、目标在后方的恢复、非法前视距离不改状态，然后运行A*到Pure Pursuit的组合仿真。

本地图中878步到达终点0.05m范围内，约17.56秒；最后位置约(6.45009,6.49995)。每个仿真采样都检查点机器人不在障碍格内。

这些离散采样检查不等于连续车体碰撞保证。Pure Pursuit可能切弯，真实部署应做车体障碍膨胀、连续轨迹碰撞检查和动态障碍处理；一条A*路径安全，不代表跟踪器走出的圆弧必然安全。

每次更新扫描路径，时间O(N)、局部长度数组O(N)，N≤256。

## 12. 编译与参考

```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic pure_pursuit.c -lm -o pure_pursuit
```

运行 ./pure_pursuit.exe。原理参考：[CMU Pure Pursuit报告入口](https://publications.ri.cmu.edu/implementation-of-the-pure-pursuit-path-tracking-algorithm)。

本例使用弧长前视选择和差速恢复策略，适用条件以本篇为准。
