# 一阶低通：每次只向新读数靠近一点

对应代码：[low_pass.c](low_pass.c)。

## 1. 核心想法
如果当前输出为 10，新读数突然变成 14，可以先走完差距的四分之一：
```text
新输出 = 10 + 0.25 × (14-10) = 11
```
下一次输入仍为 14，则输出变成 11+0.25×3=11.75。这样不会立即跳到 14，而是逐步靠近。

它不必保存一整个窗口，只保存上一次输出。输入输出单位相同。

## 2. 公式怎么来
连续一阶低通模型可以写成：
```text
tau × dy/dt = x-y
```
x 是输入，y 是输出，tau 是时间常数，单位秒。用后向欧拉近似导数：
```text
tau × (y_new-y_old)/dt = x_new-y_new
整理：
y_new = y_old + alpha × (x_new-y_old)
alpha = dt/(tau+dt)
```

dt 和 tau 都必须大于零。这样 alpha 处于 0 与 1 之间，更新就是在旧输出与当前输入之间插值。

不要把别处代码里的 alpha 直接搬过来。有些实现写成 alpha×旧值+(1-alpha)×新值，此时 alpha 的含义正好相反。

## 3. 手算示例
tau=0.03 秒，dt=0.01 秒：
```text
alpha = 0.01/(0.03+0.01) = 0.25
初始有效输入 10：直接输出 10
下一次输入 14：输出 11
再下一次输入 14：输出 11.75
再下一次输入 14：输出 12.3125
```
每次差距缩小为原来的 0.75，输出向 14 收敛。

## 4. 对照代码
LowPass 的 value 是跨采样保存的输出，initialized 区分“还没收到数据”和“输出恰好为零”。不能只用 value==0 判断是否初始化，因为零是合法读数。

第一条有效输入直接复制给 value。这样不会因为默认状态为零引入一次人为的启动爬升。

后续更新先用 double 计算 alpha 和 next，再写回 float。state->value 表示通过指针访问结构体成员。函数返回 0 时不会改动状态。

tau 和 dt 每次传入，便于采样间隔变化时重新计算系数；但不规则采样也会改变整体频率特性，不能直接照搬固定采样条件下的频响结论。

## 5. 参数该怎么调
tau 越大，跟随越慢，平滑通常越明显；tau 越小，跟随越快。

连续模型的截止频率为 fc=1/(2πtau)。这是连续原型的关系；本例采用后向欧拉离散化，离散频率响应会有偏差，尤其采样周期相对 tau 不够小时。精确数字滤波设计应分析离散频响。

低通不能自动区分高频噪声和有用的快速变化。若把姿态数据滤得很平滑却引入大延迟，控制效果可能变差。

## 6. 测试覆盖什么
示例验证：首值直接初始化；手算的 11 和 11.75；dt=0 被拒绝且状态不变；恒定输入持续 100 次后接近 14。

这些是确定性行为检查，不是对所有传感器都合适的参数证明。实际接入需要观察原始数据和滤波结果。

更新 O(1)，状态存储 O(1)。每个轴单独创建一个 LowPass；状态必须持续保存。

## 7. 编译与参考
```sh
gcc -std=c99 -Wall -Wextra -Werror -pedantic low_pass.c -lm -o low_pass
```
Windows 运行 ./low_pass.exe，Linux/macOS 运行 ./low_pass。

代码独立编写。工程级滤波实现可继续阅读 [ARM CMSIS-DSP](https://github.com/ARM-software/CMSIS-DSP)；本例不需要该库。
